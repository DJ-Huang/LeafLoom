# 页面改版与验收

## 设计与操作

以 [AppFlowy](https://github.com/AppFlowy-IO/AppFlowy)、[AFFiNE](https://github.com/toeverything/AFFiNE)、[Outline](https://github.com/outline/outline) 为界面参考，结合 [Notion 的导航与快捷搜索](https://www.notion.com/help/navigate-with-the-sidebar)，在现有 React/CodeMirror 页面中实现经典浅色文档工作台。原始文件、HTTP/MCP 接口、检索引擎和 HTML 沙箱保持现有机制。

- 白色正文、浅灰侧栏与轻量多标签；关闭当前文档后选择相邻标签。
- 侧栏默认 240px，可在 200–360px 范围拖动或使用分隔条的方向键调整。`Cmd/Ctrl+\` 收起导航，窄屏使用抽屉。
- `Cmd/Ctrl+K` 打开文件搜索，200ms 延迟查询；方向键选择、Enter 打开、Escape 关闭。原有文件搜索接口仍可能匹配标题和正文。
- 知识检索独立成页，保留知识/工时模式、证据摘录、检索通道、可信度、索引状态、降级提示和主题入口。打开来源后可返回原结果。
- 文档提供阅读/编辑/源码切换、标准/宽版切换和默认收起的文档信息。保存、文内查找、版本历史和下载位于“更多操作”，保存失败及冲突持续可见。
- 新建、模板、移动、重命名、属性和删除使用统一弹窗；原生 dialog 提供键盘焦点约束，关闭后恢复焦点。
- 最近路径和布局偏好按知识库根目录隔离。维持内存正文缓存、既有草稿机制、三个文档驻留上限和当前页面的 HTML/PDF iframe 生命周期。

本轮保留 Markdown 编辑方式。块编辑器的 Markdown 转换可能丢失信息，参见 [BlockNote 官方说明](https://www.blocknotejs.org/docs/features/export/markdown)。

## 构建与使用

前端源文件位于 `web/src/`，正式静态资源由 `npm --prefix web run build` 生成到 `vault_rag/static/`。验证时可用 `VAULT_WEB_OUTPUT` 指定独立产物目录。

使用原来的启动入口打开网页；已有页面刷新后加载新版。安装器继续依据前端源码指纹识别变更，本轮没有改变安装与服务接口。

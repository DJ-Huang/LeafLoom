# 页面改版与验收

## 设计与操作

以 [Notion 的设置分类与搜索](https://www.notion.com/help/workspace-settings) 和 [导航与快捷搜索](https://www.notion.com/help/navigate-with-the-sidebar) 为参考，在现有 React/CodeMirror 页面中统一浅色文档工作台、设置面板与操作组件。原始文件、HTTP/MCP 接口、检索引擎和 HTML 沙箱保持现有机制。

- 白色正文、浅灰侧栏；顶部显示当前文档路径，点击各级父目录返回目录列表，根目录入口返回知识库文件列表。目录内可以打开文件、进入子目录、新建和管理文件。首页与快捷搜索保留最近打开入口。
- 侧栏默认 240px，可在 200–360px 范围拖动或使用分隔条的方向键调整。`Cmd/Ctrl+\` 收起导航，窄屏使用抽屉。
- `Cmd/Ctrl+K` 打开文件搜索，200ms 延迟查询；方向键选择、Enter 打开、Escape 关闭。原有文件搜索接口仍可能匹配标题和正文。
- 知识检索独立成页，保留知识/工时模式、证据摘录、检索通道、可信度、索引状态、降级提示和主题入口。打开来源后可返回原结果。
- 文档提供阅读/编辑/源码切换、标准/宽版切换和默认收起的文档信息。保存、文内查找、版本历史和下载位于“更多操作”，保存失败及冲突持续可见。
- 设置内的新建、上传、模板与历史直接嵌入内容区。文档和目录更多菜单锚定原按钮；移动、重命名、属性和危险操作使用统一表单/确认弹窗。原生 dialog 提供键盘焦点约束，关闭后恢复焦点。
- 最近路径和布局偏好按知识库根目录隔离。维持内存正文缓存、既有草稿机制、三个文档驻留上限和当前页面的 HTML/PDF iframe 生命周期。

顶部导航已按后续反馈由多标签改为路径导航；下方文档工具栏不再重复显示路径。目录地址可在刷新后恢复，隐藏文档仍遵循原有缓存和媒体生命周期。此次路径导航调整已通过生产构建与静态差异检查，未追加浏览器验收；下表记录的是此前整体改版的验收。

本轮保留 Markdown 编辑方式。块编辑器的 Markdown 转换可能丢失信息，参见 [BlockNote 官方说明](https://www.blocknotejs.org/docs/features/export/markdown)。

## 统一设置中心（2026-10-13）

侧栏底部只保留「设置」和可点击的单行同步状态。关系图谱按后续反馈迁至侧栏主导航，设置保留 7 个分类。设置面板最大 1040×760px，分类栏宽 220px；760px 以下使用全屏分类列表与内容页。设置搜索匹配分类、功能名称和说明，选择结果后定位对应分组。

| 分类 | 内容 |
| --- | --- |
| 常规 | 关联目录、首页 |
| 文件与导入 | 可修改的目标目录、新建笔记/目录、上传、模板创建与打开结果 |
| 模板与写入 | 模板目录、日记目录、各类写入位置 |
| 检索与索引 | 检索包含/排除、专用目录、BGE-M3、同步进度与重新同步 |
| AI 集成 | wiki-search 安装、更新与状态 |
| 操作历史 | 目录操作、文档版本、按路径筛选与恢复 |
| 回收区 | 恢复、永久清空与空状态 |

配置使用面板级草稿，切换分类不丢失，统一保存/取消。保存成功留在当前分类；保存失败保留输入。关闭面板或打开结果前，可保存、放弃更改或继续编辑。浏览器刷新同样提示未保存配置。检测到外部配置更新时保留草稿并阻止覆盖，提供重新载入入口。

关联目录改动尚未保存时，依赖目录的功能暂停展示。切换知识库会清理面板中的记录筛选、目标目录和待打开结果；异步结果检查所属知识库和操作代次，旧请求不能更新新知识库界面。清空回收区继续使用已有根目录校验及确认参数。文件操作、模型准备和技能安装与配置草稿独立执行，执行时禁用重复操作与分类切换。

全站共用字体层级、灰色悬停/选中态、细分隔线、按钮、菜单和提示样式，覆盖首页、文件目录、搜索、文档工具栏、表格/看板/日历、媒体外框及首次关联页。嵌入网页本身的内容与样式保持原样。

### 复现设置功能验收

先构建到独立输出目录，再用测试服务启动临时知识库。测试服务禁用后台模型与索引任务，不读取真实知识库配置。需要环境中已有 Playwright 与 Chromium。

```sh
VAULT_WEB_OUTPUT=/private/tmp/vault-settings-build npm --prefix web run build
.venv/bin/python tests/settings_ui_server.py /private/tmp/vault-settings-build
```

另一个终端运行：

```sh
SETTINGS_TEST_URL=http://127.0.0.1:18082 node tests/frontend_settings.cjs
```

可用 `VAULT_SETTINGS_TEST_PORT` 调整测试端口，`SETTINGS_TEST_ARTIFACTS` 指定截图和 JSON 报告目录。默认报告位置为 `.cache/settings-ui-artifacts/`。每次重新启动测试服务都会创建新的系统临时知识库。脚本拒绝生产端口和不属于隔离目录的知识库。

## 关系图谱重构（2026-10-13）

按后续反馈，关系图谱已从设置迁到侧栏主导航，位于「知识检索」下方，支持 `/?view=graph` 直接访问。参考 [Obsidian Graph view](https://obsidian.md/help/plugins/graph) 的节点大小、分组颜色、连接高亮、独立笔记过滤和局部层级；用现有 Cytoscape 渲染，并显式声明已有的 d3-force 依赖，在 Worker 中计算力导向布局。后台接口和笔记格式不变。

- 替换超过 100 个节点时的同心圆布局。默认隐藏无邻居的独立笔记，清楚显示「可见 / 总数」；可在筛选中恢复全部。去掉重复方向相同的连线与无效端点，连接数按去重后的有向连接计数。
- 按一级目录着色，节点大小反映相连笔记数。总览优先显示连接较多的节点名称，放大后逐步显示其他名称并避让重叠；可手动打开全部名称、连接方向。
- 搜索标题或路径，可用方向键与 Enter 定位。单击节点显示笔记路径、相连笔记列表与「打开笔记／探索连接」，悬停高亮相邻连接。局部图谱支持 1–3 层。
- 拖动画布或节点，滚轮／双指缩放；按钮支持放大、缩小、适应画布与重新布局。画布获得焦点后支持方向键平移、加减号缩放、0 适应、Escape 清除选择。
- 打开文档后提供「返回关系图谱」，保留当前筛选、选择与画布；打开设置同样保留图谱状态。切换知识库卸载旧图谱，终止旧布局 Worker 和读取请求。
- 手机端使用完整画布，详情接在画布下方并可滚动访问操作。样式仅作用于图谱页面。

### 图谱浏览性能优化（2026-10-13）

定位到缩放事件原先每帧都会排序节点、计算文字避让、写入全图样式并触发页面更新；悬停也会反复清除和重设全图高亮。

- 连续缩放／平移期间只变换视口，停止 120ms 后再整理标签、尺寸和缩放读数；平移后不重复写入未变化的尺寸和连线样式。
- 节点优先级与估算文字宽度在数据加载后缓存。仅为画布内的节点安排普通标签，自动标签最多 120 个；「全部名称」仍可手动开启。
- 悬停稍作合并，高亮切换只修改邻域差集，重复高亮相同节点不再触发样式更新；移动画布和拖动节点时暂停悬停切换。
- 超过 400 个可见节点时启用 Cytoscape 的视口纹理缓存，移动时复用已绘制画面，停下后恢复细节。参见 [Cytoscape 渲染选项](https://js.cytoscape.org/#init-opts/rendering)。

验证：生产构建及图谱专项检查通过。1,280 节点测试图中的连续视口变换不再调用应用的全图几何样式更新，停下后执行恢复；搜索、筛选、局部探索、打开返回、选中邻居高亮及窄屏检查保持通过。本轮验证针对更新行为，不提供未测量的帧率或加速倍数。

### WebGL2 绘制（2026-10-13）

图谱默认启用 [Cytoscape WebGL 渲染](https://blog.js.cytoscape.org/2025/01/13/webgl-preview/)，由 WebGL2 绘制节点、文字与连线，并使用 GPU 拾取节点。保留后台 Worker 布局与前述交互更新合并。当前使用的直线／haystack 连线、三角箭头和文字样式在该模式的支持范围内；由于上游仍将其标为预览功能，将依赖固定到已验证的 3.34.3。

- 右上角显示「WebGL 加速」；探测不到 WebGL2 时使用「兼容绘制」，并仅在该模式的大图中保留视口纹理缓存。
- WebGL 可用不等于浏览器一定使用硬件 GPU。默认无头 Chromium 的检测结果为 SwiftShader 软件实现；本机 Metal 模式的检测结果为 `ANGLE (Apple, ANGLE Metal Renderer: Apple M4 Pro, Unspecified Version)`。
- 图形上下文中断时显示可重试提示，重新连接保留节点位置、缩放、平移与当前选择；初始化分配失败也提供重试。卸载或切换范围会释放 GPU 上下文与 Worker。
- 生产构建通过。Apple Metal 路径下的 12 组图谱检查通过（包含 1,280 节点数据、缩放／拖动、筛选、窄屏和高亮），无页面脚本错误。
- 新的 `tests/frontend_graph_gpu.cjs` 验证实际 WebGL2 上下文、真实坐标点击的节点拾取、上下文丢失与位置恢复、无 WebGL2 的兼容模式及初始化失败重试。未进行帧率基准，不承诺固定加速倍数。

使用同一隔离测试服务复现：

```sh
SETTINGS_TEST_URL=http://127.0.0.1:18082 node tests/frontend_graph_gpu.cjs
```

macOS 上可添加 `GRAPH_TEST_METAL=1` 验证 Metal 后端；这只设置测试浏览器启动参数，不修改用户浏览器或系统配置。

# LeafLoom桌面测试版

安装后直接打开独立 App。Windows 安装包为 `.exe`；macOS Apple 芯片安装包为 `.dmg`，将“LeafLoom.app”拖入 Applications 后打开。

运行环境随包附带，无需安装 Python、Node 或下载源码。首次在 App 内下载 BGE-M3；下载期间可以浏览、编辑和使用关键词检索。模型准备完成后可离线使用。

关闭窗口后继续后台运行，托盘/菜单栏提供打开窗口、重启服务、日志和退出。新安装默认关闭登录启动，可以在设置中开启；旧版升级保留原有选择。

覆盖升级前请正常退出 App。Windows 安装程序会请求保存并正常停止后台，保存冲突或停止超时时中止更新。Mac 请先退出，再用新版替换原 App。用户配置、模型、知识库文件、索引、历史和回收区保留。浏览器草稿与界面偏好不自动转入 App，迁移前请在旧浏览器保存草稿。

这是测试版：默认未配置 Windows 发布者证书，Mac 使用临时签名、未公证。Windows 可能显示未知发布者；Mac 下载版如被系统拦截，可核对下载来源及 SHA256 后，在“系统设置 → 隐私与安全性”中允许打开。正式签名发行包以具体发布说明为准。

支持 Windows 10/11 x64、macOS 14+ Apple 芯片。自动化验收结果和待人工检查项目随 release 附带，未检查项目不代表通过。首版采用手动下载安装包更新。

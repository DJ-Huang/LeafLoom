# LeafLoom 0.1.10 — デザインプロジェクトを開いて共有

リリース日：2026-11-19 · v0.1.9 からの変更

[English](../en/RELEASE_NOTES_0.1.10.md) · [中文](../zh-CN/RELEASE_NOTES_0.1.10.md) · [日本語](../ja/RELEASE_NOTES_0.1.10.md)

保管庫外の既存 Design Studio プロジェクトを読み取り専用で開けます。変更を保存する場合は編集を有効にしてください。一覧から削除してもディスク上のファイルは残ります。

プロジェクトを ZIP として書き出し、別の保管庫へ独立したコピーとして取り込めます。既存フォルダーは上書きしません。

更新前に保管庫とメタデータをバックアップし、LeafLoom を終了して対応するパッケージをインストールし、同じ保管庫を開き直してください。ソース版は更新後に再起動します。Windows x64 は未署名、macOS 14+ Apple Silicon はアドホック署名で Apple 公証なしです。インストール前に成果物、SHA256SUMS.txt、ビルド結果を確認してください。

# リンク・バックリンク・グラフを使う

## できること

関連メモを移動し、つながりを発見します。

## 始める前に

Markdown メモを 2 件以上用意します。意味検索モデルは不要です。

## 操作手順

1. `[[` と名前を入力し、候補のフルパスから選びます。
2. 対象のメモを開き、バックリンクを確認します。
3. グラフで名前やフォルダーを絞り、線をたどります。
4. 同名メモには相対フルパスを使い、移動や改名はできるだけ LeafLoom で行います。

![グラフ](../../../assets/screenshots/ja/05-graph.png)

## 完了後の状態

グラフは Markdown のリンク関係で、意味の近さや根拠の信頼性を保証しません。

## うまくいかないとき

線がないときは対象・綴り・フィルターを確認します。外部で改名したら参照を確認します。

# 最初の保管庫を接続する

## できること

ローカル資料を選び、閲覧と検索の範囲を設定します。

## 始める前に

デモで練習し、実際のメモは接続前にバックアップします。

## 操作手順

1. ようこそ画面でデモ、または自分のフォルダーを選びます。
2. 接続して続行します。ファイルは元の場所に残り、以後の保存は原本を変更します。
3. 知識検索の対象を選ぶか、閲覧だけで始めます。
4. 探索を開始します。対象と範囲は設定で変更できます。

![ようこそ画面](../../../assets/screenshots/ja/01-welcome.png)

## 完了後の状態

索引の準備中も閲覧できます。言語ごとのデモは独立し、変更を保持します。

## うまくいかないとき

ローカルパスを使います。UNC 共有・シンボリックリンク・junction を通じたアクセスは非対応です。

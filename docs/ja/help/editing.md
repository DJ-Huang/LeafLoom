# Markdown・表・数式を編集する

## できること

整形された本文に入力し、必要に応じて Markdown ソースに切り替えます。

## 始める前に

ローカルフォルダーを接続します。まずはデモ保管庫で試せます。

## 操作手順

本文の行頭または空白の後に `/` を入力すると、見出し、リスト、ToDo、引用、表、コード、画像、リンク、数式、Mermaid 図を挿入できます。メニューにはアイコン、説明、分類、最近使った項目が表示されます。名前や `/h2`、`/todo` などで絞り込み、矢印キーと Enter で選択します。Esc は入力を残して閉じます。コード、数式、プロパティ、URL 内では開きません。

文字を選択すると書式ツールバーが表示されます。`Ctrl/⌘+B`、`Ctrl/⌘+I`、`Ctrl/⌘+E` で太字、斜体、インラインコードを切り替えます。選択文字に URL を貼り付けるか、`Ctrl/⌘+Shift+K` でリンクを入力できます。`[[` とノート名を入力すると、パスでノートを選べます。

ブロックにカーソルを重ねると **＋** とハンドルが表示されます。ハンドルのメニューで変換、複製、上下移動、削除ができ、ドラッグで段落、リスト項目、ブロック全体を並べ替えられます。段落をまたいで文字を選択でき、表のセルも直接編集できます。Tab でセルを移動し、最後のセルでは行を追加します。表のツールバーで行列、見出し、配置を変更できます。添付は保管庫共通の `_attachments` フォルダー（または設定済みの `attachment_folder`）に一意の名前で保存し、既存ファイルは上書きしません。リンクを元に戻しても添付は残り、失敗やキャンセル後も完了済みのファイルは残ります。ノート内の画像を右クリックして **画像をコピー** を選ぶか、画像を選択して `Ctrl/⌘+C` で PNG をシステムクリップボードに書き込み、他のアプリやメモへ貼り付けられます。

保存形式は通常の Markdown のままです。変更していないブロックやプロパティは元のテキストを保持し、本文とソースで元に戻す履歴を共有します。数式と Mermaid は整形して表示し、専用パネルで変更します。直接編集できない複雑な内容は表示を保ち、該当するソースへ移動して編集できます。言語の変更でも編集状態と履歴を保持します。表は Markdown の単純な構造に対応し、セルの結合やセル内の入れ子ブロックは含みません。

**このページの目次** は現在の Markdown メモの見出しを、本文左側の罫線のない一覧に階層表示します。左上の二重矢印で閉じ、同じ位置に残るリストアイコンで開きます。下位見出しのある項目は、見出しの文字をクリックして子階層全体を開閉し、同時に該当箇所へ移動できます。左側の矢印は開閉のみを行い、下位見出しのない項目は移動のみを行います。編集や目次全体の開閉でも各階層の状態を保持し、閉じた階層内を読んでいる間は上位見出しを強調して自動では開きません。読んでいる節を青色で示し、本文のスクロールに追従します。見出しをクリックすると本文・ソースの該当箇所を画面上部へ移動します。編集時にも更新し、下線形式の見出しや同名の見出しを区別します。コードブロックとプロパティは含めません。現在のセッションでメモごとに開閉を記憶します。文書領域が狭い場合は既定で閉じ、開くと重ねて表示します。上位見出しの開閉では表示を保ち、下位見出しのない項目の選択か Esc で閉じます。

## 完了後の状態

通常の変更は自動保存され、本文とソースで元に戻す履歴を共有します。

## うまくいかないとき

複雑な構造はソースで確認します。AI の下書きは明示的に保存します。

# 検索結果がない・索引が未準備の場合

## できること

ファイル・対象範囲・索引・モデルの順に確認します。

## 始める前に

原本を残し、確実に存在する Markdown・TXT を選びます。

## 操作手順

1. `Ctrl/⌘+K` で名前・パス・現在の保管庫を確認します。
2. 対象フォルダー、除外、`.ragignore`、メモの索引除外属性を確認します。
3. HTML と添付は意味検索ではなく閲覧・添付管理で探します。
4. モデル取得・検証・索引作成・キーワードへの切り替えを区別します。
5. 必要なら索引を再同期し、進捗を見て原文の語句で試します。

## 完了後の状態

ファイル探し・対象選択・意味検索の準備の問題を切り分けられます。

## うまくいかないとき

最初から再インストールや索引削除をせず、診断を残します。準備完了でもすべての質問に結果があるとは限りません。

# 最初のメモを作って見つける

## できること

作成・編集・リンク・再表示を一度試します。

## 始める前に

[接続済みの保管庫](first-vault.md)、できればデモを使います。

## 操作手順

1. 新規メモから既存の親フォルダーと未使用の名前を選びます。
2. 本文を入力し、`/h2` で見出し、`/todo` でタスクを挿入します。
3. `[[` を入力し、フルパスから別のメモを選びます。
4. 自動保存を待ち、別のメモに移動してから戻ります。
5. `Ctrl/⌘+K` で名前を検索して再表示します。

## 完了後の状態

通常の Markdown ファイルが作られ、他のエディターでも読めます。

## うまくいかないとき

AI の手動下書きは保存ボタンか `Ctrl/⌘+S` で保存します。競合時は下書きを残します。

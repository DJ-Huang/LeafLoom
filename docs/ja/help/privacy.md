# ローカルデータと外部アクセスを理解する

## できること

内容がローカルに残る場合と、外部へ送られる場合を知ります。

## 始める前に

閲覧・選択した検索範囲・AI 参照・MCP 全体権限を区別します。

## 操作手順

1. 閲覧・グラフ・検索はローカルで、モデル初回取得は通信します。
2. AI へ送る前に選択文・現在のメモ・検索引用を確認します。設定した提供元が受信する場合があります。
3. MCP の結果は呼び出したクライアントへ渡り、全体権限は RAG 外も含みます。
4. Feishu はクラウドへ接続し、ローカルメモへ自動同期しません。
5. 認証情報とバックアップを保護し、本機ポートを公開サービスとして開放しないでください。

## 完了後の状態

接続・資料・書き込みを別々に許可できます。公開ヘルプは静的で保管庫を読みません。

## うまくいかないとき

分離された HTML でも不明なページやスクリプトを確認します。OS アカウントとバックアップの保護も必要です。[技術的な境界](../../SECURITY.md)。

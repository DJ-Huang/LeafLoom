# 未保存下書きと版の競合を解決する

## できること

変更を残し、ディスクや別クライアントの新しい内容と比較します。

## 始める前に

再読込や唯一の下書きの破棄、古い書き込みの連打を避け、大切な下書きを退避します。

## 操作手順

1. 自動保存か、AI 反映後の手動下書きか確認します。
2. 手動下書きは保存か `Ctrl/⌘+S` を使います。
3. ディスクが変わった場合は両方を読み、明示的に統合します。
4. デザインは未送信の変更を保持します。通信失敗は再試行し、版の競合は確認後に再適用します。
5. MCP も版を再取得します。別ウィンドウがコメントを変えた場合、取り消しは停止します。

## 完了後の状態

保存を確認してから移動・プレビュー・終了します。

## うまくいかないとき

保存と索引更新は別です。索引待ちのために同名内容を再作成しないでください。

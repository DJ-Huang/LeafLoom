# 言語・フォルダー・再起動・常駐設定

## できること

日常設定を変更し、正しく再起動・終了します。

## 始める前に

手動の AI 下書きを含め、作業を保存します。

## 操作手順

1. 一般設定で中国語・英語・日本語・システム言語を選びます。
2. 設定で保管庫を変更します。パスと検索範囲は現在の保管庫に従います。
3. ログイン時の起動はデスクトップ設定やトレイで変更でき、初期状態は無効です。
4. メニューの LeafLoom を再起動を使います。未保存の確認で戻れば中止します。
5. 閉じると常駐し、終了でサービスと接続を止めます。

## 完了後の状態

言語変更は文書・下書き・位置を保ち、索引を作り直しません。Dev は Vite を保持して依存関係を同期します。

## うまくいかないとき

Dev とインストール版は実データとポートを共有します。切り替え前に終了し、検証には明示的な独立データ先を使います。

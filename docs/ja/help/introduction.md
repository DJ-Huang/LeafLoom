# LeafLoom でできること

## できること

自分のファイルで、編集・検索・関連付けができる個人知識ベースを作ります。

## 始める前に

ローカルの資料フォルダー、または内蔵の架空デモを用意します。

## 操作手順

1. Markdown を編集し、リンク・プロパティ・グラフで関連付けます。
2. ローカル検索の対象を選び、必要なときに意味検索モデルを準備します。
3. 添付・HTML プロジェクト・デザイン画面を管理します。
4. 任意で AI 対話・MCP・Feishu を接続します。

## 完了後の状態

メモは元の場所に残り、索引・履歴・ごみ箱は `.vault-rag/` に保存されます。

## うまくいかないとき

クラウド同期やすべての Obsidian プラグインには対応しません。外部 AI と Feishu は通信します。

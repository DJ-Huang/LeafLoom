# 意味検索モデルと索引を準備する

## できること

意味検索が必要なときにローカル BGE-M3 を準備します。

## 始める前に

検索範囲を選びます。初回はネット接続と空き容量が必要です。

## 操作手順

1. 設定の検索と索引でモデルの状態と保存先を確認します。
2. ダウンロードを開始し、接続・取得・検証を確認します。
3. 設定を閉じても続きますが、アプリ終了で中断します。診断を残して再試行すると取得済みファイルを再利用できます。
4. モデルの準備後、別の索引作成が終わってから意味検索を試します。

## 完了後の状態

閲覧と編集は使えます。キーワード・Wiki への切り替えは意味検索の準備完了を表しません。

## うまくいかないとき

30 秒更新がなければ待機を表示します。モデルフォルダーを開くだけでは取得しません。メモは削除しないでください。

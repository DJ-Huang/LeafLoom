# メモ・コメント・復元データを保護する

## できること

索引から再生成できない原本とユーザー記録を保護します。

## 始める前に

本文と AI 下書きを保存し、外部編集・同期を止め、正常に終了します。

## 操作手順

1. 非表示の `.vault-rag/`、添付、HTML、デザインを含む保管庫全体をバックアップします。
2. `annotations.sqlite` はコメントとハイライトです。履歴・ごみ箱・添付整理の原本も復元用データで、キャッシュではありません。
3. 設定・モデル・認証情報・AI 履歴は通常 Windows の `%LOCALAPPDATA%\VaultRag`、Mac の `~/Library/Application Support/VaultRag` にあります。
4. 唯一の未保存下書きは別途書き出し、バックアップを読めるか確認します。
5. 新しいフォルダーに復元して確認してから既存資料を置き換えます。

## 完了後の状態

原本とユーザー記録を保護できます。ローカルの索引やごみ箱だけでは別端末のバックアップになりません。

## うまくいかないとき

別のコンピューターでは OS 暗号化された認証情報の再認可が必要な場合があります。バックアップを公開しないでください。

# 添付を閲覧・プレビュー・アップロードする

## できること

専用ワークスペースで添付を探し、メディアをプレビューし、原本をダウンロードします。

## 始める前に

> **対応バージョン：** この添付ワークスペースと整理機能は [v0.1.4 インストーラー](https://github.com/DJ-Huang/LeafLoom/releases/tag/v0.1.4)に含まれています。v0.1.3 には含まれていません。旧版を使用している場合は、保管庫をバックアップして更新してから、以下の手順を進めてください。

ローカルフォルダーを接続します。まずはデモ保管庫で試せます。

## 操作手順

Base64 一括送信には、この変更を含むビルドが必要です。

ナレッジベースの添付は `vault_files_update` の `request.action="upload"` を使います。ChatGPT では `source="files"` とホストが提供するトップレベルの `files` 配列を優先します。ローカルクライアントは `source="base64"`、`name`、`data_base64`、元バイト列の `sha256` により 2 MiB 以下を一括送信できます。それ以上は begin/chunk/commit を使います。`folder` を省略すると設定済み添付フォルダーを使い、`Comics/Project/assets` などの保管庫内相対パスも指定できます。

`vault_index_status` の `workspace_revision` と一意の `operation_id` が必要です。同一引数の再試行では同じ ID を使います。結果は保存先、サイズ、SHA-256、リビジョン、`markdown_link` を返し、画像には `markdown_embed` も返します。`vault_files` の stat に `source_note` を指定するとノート相対リンクを取得できます。ノートの現在のリビジョンを使って Markdown を更新してください。同名の元ファイルは保持されます。

Design Studio のインポートや Feishu の一時転送しか表示されない場合、サーバーの `tools/list` に `vault_files` と `vault_files_update` があるか確認します。更新済みバックエンドの再起動に加え、クライアントのプラグインツール一覧を更新／再スキャンしてください。LeafLoom の再起動だけではクライアントのキャッシュは更新されません。保管庫の書き込み権限も確認してください。通常の添付に Feishu 権限は不要です。[MCP ファイルツール](mcp.md)を参照してください。

AI クライアントも `vault_files`（読み取り・ダウンロード・状態）と `vault_files_update`（アップロード・管理）で同じ添付システムを使用できます。**AI 連携** で保管庫のアクセスを有効にし、書き込みを別途許可します。チャットファイルはバックグラウンドで転送し、ローカルクライアントはサイズとハッシュを検証した分割バイト列を送れます。失敗時は完了済み結果を確認して残りを再試行してください。読み取りには現在の版が必要で、移動と回収は計画・復元記録を保持します。[MCP の設定](mcp.md)も参照してください。

サイドバーの **添付ファイル** から専用ワークスペース（`?view=attachments`）を開きます。上部に総件数、使用容量、索引の状態を表示します。保管庫全体のファイル名・相対パスを検索し、種類で絞り込み、名前・更新日時・サイズで並べ替え、サムネイルと一覧を切り替えられます。初期表示はサムネイル、更新日時の降順です。1 ページ最大 100 件で、全選択は現在のページだけに適用され、ページ・検索・絞り込み・並び順の変更で解除されます。

初回は状態確認のみです。**初期化して整理を準備** を一度押すと、索引の準備・更新、保護対象の依存関係の確認、整理計画の作成をバックグラウンドで進めます。索引が使用可能になれば、分析中でも閲覧できます。対応する旧索引はバックアップし、未知の版は上書きしません。総数が不明な間は処理済み件数と動作中の表示を使い、完了率は表示しません。**タスク** では日時、状態、結果を確認でき、開き直すと保存済みの処理に再接続します。索引だけの保守は詳細設定にあります。

ファイルを選ぶと右側でプレビューできます。画像は拡大縮小、ドラッグ、画面に合わせる、拡大表示に対応し、PDF は埋め込み表示、音声・動画は内蔵プレーヤーで再生します。ファイルの切り替えや画面を離れた時に再生を停止します。狭い画面ではプレビューから一覧に戻っても条件とスクロール位置を保持します。その他の形式は詳細と元ファイルのダウンロードを表示し、デスクトップでは **ファイルマネージャーで表示** も使えます。HTML は実行せず、SVG は画像として表示します。サムネイルはデコード容量と同時処理数を制限して必要時に生成・キャッシュし、失敗時は形式アイコンに戻ります。

**アップロード** または複数ファイルのドロップで、統一保存先（既定 `_attachments`）に追加します。同名でも両方を保持し、上書きしません。進捗と再試行はタスクで確認します。ノート（`.md`、`.txt`、`.base`）はエディターやファイルブラウザーで管理してください。選択したファイルを ZIP ダウンロード、一括移動、回収できます。名前の変更は一つずつ行います。ZIP はバックグラウンドで準備し、1 時間で期限切れになります。

名前の変更と移動は、対応する静的 Markdown のインライン・参照リンクと Wiki リンク・埋め込みを分析して計画を作成します。検出された参照、パス、ブロック項目を確認し、一度の確認で実行します。参照のある添付の回収でも対象ノートを表示し、確認を求めます。ノートのリンクは削除・書き換えず、必要に応じて添付を復元します。「検出された参照」は全参照の検出を保証する表現ではありません。本版では Office 変換、本文・OCR 検索、重複整理、一括命名テンプレートは提供しません。


## 完了後の状態

同名ファイルは両方を残します。プレビュー非対応でも原本を取得できます。

## うまくいかないとき

索引が未準備なら初期化します。HTML プロジェクトの素材は保護対象です。

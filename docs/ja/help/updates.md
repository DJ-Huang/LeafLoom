# 更新を確認してインストールする

## できること

版を確認し、通常のインストール手順で更新します。

## 始める前に

作業を保存し、[変更履歴](../CHANGELOG.md)を読み、大切な内容をバックアップします。

## 操作手順

1. 一般設定のアプリ更新から更新を確認します。
2. 新版をダウンロードし、進行状況を確認します。
3. SHA-256 検証後に正常終了します。終了を中止した場合は後でインストールを続けられます。
4. Windows は案内に従い、Mac は DMG からアプリを置き換えて再起動します。
5. Dev は確認だけです。ソースを更新して Dev を再実行します。

## 完了後の状態

メモ・設定・索引・モデルは保持しますが、事前のバックアップも推奨します。

## うまくいかないとき

通信失敗は再試行できます。ページ更新だけではバックエンドは更新されません。各 OS の実際の配布版表示に従います。

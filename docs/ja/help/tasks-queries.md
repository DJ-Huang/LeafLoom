# タスク・データビュー・プロパティ検索

## できること

プロパティ付きのメモを表・タスク・カレンダーで表示します。

## 始める前に

デモの架空タスクとサンプルビューで試します。

## 操作手順

1. `status`・`priority`・`due` などを統一します。
2. `.base` を開き、設定された表・タスクリスト・看板・カレンダーを切り替えます。
3. 書き込み可能な項目やタスク状態を変更すると、元のメモに保存されます。
4. `file.*` と数式は読み取り専用です。プロパティ検索は制限付き TABLE/LIST 構文で、任意のコードは実行しません。

### ノートデータベース

ディレクトリー見出しまたはメニューの **データベースを作成** で `.base` と記録フォルダーを設定します。テーブル、リスト、ボード、ギャラリー、ドラッグ可能なタイムラインは同じ Markdown ノートを使います。ツールバーでフィールド、フィルター、並べ替え、グループ、レイアウトを設定し、記録からプロパティと本文を編集します。エディターの **データベースを挿入** でビューを埋め込みます。フィールド・ビューを削除してもノートの値は保持され、記録の削除は復元可能なゴミ箱に移動します。[詳しい手順](../GUIDE.md#ノートデータベース)。

## 完了後の状態

ビューは原本の表示方法です。移動や項目編集は元ファイルを変更します。

## うまくいかないとき

Dataview や TaskNotes の全機能には対応しません。エラー時は項目と設定を確認します。

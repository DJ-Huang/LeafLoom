# LeafLoom をインストールする

## できること

デスクトップアプリをインストールし、ようこそ画面を開きます。

## 始める前に

[動作要件](requirements.md)を確認し、他の作業を保存します。

## 操作手順

1. [公式サイト](../../../README.md)から Windows または Mac のパッケージを選びます。
2. Windows は `LeafLoom-*-windows-x64-setup.exe` の案内に従い、スタートメニューから開きます。
3. Mac は `LeafLoom-*-macos-arm64.dmg` を開き、アプリケーションへドラッグしてから起動します。
4. ブロックされたら入手元と[インストールの問題](installation-problems.md)を確認します。
5. 言語を選び、デモか自分のフォルダーを開きます。

## 完了後の状態

モデルの事前ダウンロードなしで保管庫を選べます。

## うまくいかないとき

現在のパッケージには信頼済みの配布署名がなく、Mac はアドホック署名・未公証です。OS 全体の保護を無効にしないでください。

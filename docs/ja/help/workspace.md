# ワークスペースの入口を知る

## できること

ファイル・検索・添付・デザイン・設定の入口を使い分けます。

## 始める前に

保管庫を開きます。言語は一般設定で変更できます。

## 操作手順

1. 左のツリーでファイルを開き、ホームで最近の内容やチェックリストを確認します。
2. 知識検索は根拠、グラフは関連、`Ctrl/⌘+K` はファイル名を探します。
3. 添付管理でメディア、プレビューで URL、デザインスタジオでプロジェクトを開きます。
4. AI 対話は任意です。設定で範囲・接続・履歴・ごみ箱を管理します。
5. はじめてのガイドはチェックリスト、ヘルプセンターは現在の言語の文書を開きます。
6. 上部のパスバーでフォルダー名やファイル名を右クリックし、**相対パスをコピー** または **絶対パスをコピー** を選びます。相対パスは保管庫のルート基準（ルート自体は `.`）、絶対パスはサービス実行側の形式です。パスにフォーカスして **Shift+F10**、または現在のファイル名・フォルダー名のクリックでも開けます。

## 完了後の状態

内容に合うワークスペースへ移動できます。閲覧だけなら検索対象の選択は不要です。

## うまくいかないとき

ウィンドウを閉じるとトレイに残ります。サービスも停止する場合は終了を選びます。

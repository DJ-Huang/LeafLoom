# AI・MCP・Tunnel・Feishu の接続を調べる

## できること

失敗した層を特定してから、接続や権限を直します。

## 始める前に

接続種別・版・脱敏エラー・最近の更新や鍵再生成を記録します。

## 操作手順

1. AI 対話は CLI の実行とログインを確認し、PATH 変更後は再起動します。
2. ローカル MCP はアドレス・専用鍵・読み取り許可を確認し、更新後にツールを読み直します。
3. Tunnel は ID・App Key・状態を確認し、同じ設定の受管インスタンスは 1 件にします。
4. Feishu は CLI 認可後、対象文書や表の権限を確認します。`leafloom_mcp` はローカル、`feishu_cli` は上流のエラーです。
5. 書き込みのタイムアウト・不明・部分成功後は実際の資料を読んでから再試行を判断します。

## 完了後の状態

クライアントのキャッシュ・本機権限・通道状態・クラウド権限を区別できます。

## うまくいかないとき

設定や鍵を公開せず、全書き込みを許可して調査しないでください。状態確認だけで資料へのアクセスは証明できません。

# MCP 権限と認証情報を管理する

## できること

接続ごとの読み書き対象を管理します。

## 始める前に

ローカル AI と ChatGPT Tunnel を区別します。書き込みは両方とも初期状態で無効です。

## 操作手順

1. 設定の AI 接続、MCP 権限で対象の接続を選びます。
2. メモや Feishu の読み取り、必要なら別途書き込みを許可します。メモ全体には RAG 対象外も含みます。
3. 初回表示の専用設定を対象クライアントに非公開で保存します。
4. Feishu の高リスク操作は専用スイッチと毎回の確認が必要です。
5. 再生成後はクライアントを更新します。全権限の無効化か再生成で旧認証情報が失効します。

## 完了後の状態

一つの権限を止めるとその資料だけを遮断します。旧接続に自動で全権限を付けません。

## うまくいかないとき

認証エラーは接続先と鍵を確認します。調査のために全書き込みを開放しないでください。MCP の鍵は UI や Feishu のログイン用ではありません。

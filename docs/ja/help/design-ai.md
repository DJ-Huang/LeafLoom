# AI で現在のデザインを変更する

## できること

選択したプロジェクトの文脈を渡し、取り消せる AI 変更を適用します。

## 始める前に

デザインプロジェクトを開き、保存の完了を待ちます。

## 操作手順

Design Studio で要素を選択し、**AI チャットに追加** でプロジェクト、ページ、安定した ID、現在のリビジョンを添付します。レイアウト、素材、コンポーネント、アニメーション、スクリプトの変更を依頼できます。内蔵アシスタントが変更できるのは、現在の会話に明示的に添付したプロジェクトだけです。一括変更は直接適用され、一度で元に戻せる永続履歴になります。バージョン競合では新しいデザインを保持し、スクリプトの再生状態は保存しません。スクリプト API と書き出しは [Design Studio](../../DESIGN_STUDIO.md) を参照してください。

外部 AI では、キャンバスの要素またはレイヤー一覧を右クリックし、**要素の位置情報をコピー** を選んで変更内容とともに貼り付けます。プロパティパネルでも現在の選択をコピーできます。Shift キーで複数選択し、選択済みの要素を右クリックすると選択を保持します。簡潔な JSON はソースの絶対パス `file`、`page_id`（または `component_id`）、単一選択の `node_id` または複数選択の `node_ids` 配列のみを含み、該当時のみ `variant_id` や `has_pending_changes:true` を追加します。保存完了を待ち、AI は最新版を読み、バージョン検査付きのデザイン操作で履歴を保持して変更してください。

キャンバスまたはレイヤーにフォーカスがあるとき、Mac は **⌘+C**、Windows は **Ctrl+C** で画像以外の単一要素や複数要素の位置情報をコピーできます。単一画像は元画像をコピーし、その位置情報には **要素の位置情報をコピー** を明示的に選択してください。テキスト編集中、入力欄、ソースエディター、通常の文字選択では標準のコピー動作を保ち、プレビューには影響しません。

**元画像をコピーする。** Design Studio で画像を1つ選び、右側の **デザイン** タブで **画像の元ファイル → 画像をコピー** を選択します。縮小画像、ファイル名、保管庫内の相対パスを表示し、バインディング、バリアント、画像をルートとするコンポーネントの上書きを反映します。元画像のサイズと透明背景を保持し、キャンバスの切り抜き・角丸・回転は含めません。ロック中の画像や読み取り専用のバリアントでもコピーでき、保存や履歴の追加は行いません。キャンバスかレイヤー一覧にフォーカスがある場合、**⌘C / Ctrl+C** で単一画像をコピーします。他の要素や複数選択では位置情報をコピーし、画像メニューの **要素の位置情報をコピー** も利用できます。入力欄の文字コピーは通常どおりです。PNG を他のアプリやメモへ貼り付けでき、メモでは既存の添付アップロードを利用します。SVG は画像化し、アニメーションは最初のフレームのみを使用します。プロジェクト内の元画像のみ対応し、外部画像は先に取り込んでください。欠落・読込・デコード失敗時は理由と再試行を表示し、リンクや文字には置き換えません。元ファイルと PNG は32 MiB以下、画像は6400万画素以下です。ネイティブコピー機能の更新後はデスクトップ版を再起動してください。

## 完了後の状態

MCP はページ分割した要約を既定で返します。ページ／要素またはリソース ID を選び、`full=true` で必要なソースを読み取ります。`next_offset` には `expected_revision` を渡し、変更と取り込みは短い結果を受け取ります。選択条件なしの `full=true` と変更ツールの `include_document=true` で文書全体も取得できます。更新後はバックエンドを再起動し、ツールを更新してください。[MCP 仕様](../../MCP.md)を参照してください。

デザインの変更は直接適用され、一括変更ごとに履歴から元に戻せます。

## うまくいかないとき

デスクトップ版ではシステムのクリップボードを使用します。更新後は LeafLoom を再起動して新しいコピー機能を有効にしてください。

競合時は新しいデザインを確認し、古い変更を繰り返し送信しないでください。

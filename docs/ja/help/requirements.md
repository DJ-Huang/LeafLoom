# 利用前に準備するもの

## できること

自分のコンピューターに合うインストール方法を選びます。

## 始める前に

Windows 10/11 x64、または macOS 14 以降の Apple Silicon を用意します。

## 操作手順

1. 対応するインストーラーを公式サイトから取得します。Intel Mac は非対応です。
2. 読み書き可能なローカルフォルダーを選び、大切な資料をバックアップします。
3. ダウンロードや外部サービスには接続が必要です。
4. 一般利用者に Python・Node・uv・Ollama・ソース取得は不要です。

## 完了後の状態

インストール後、閲覧・編集・グラフ・キーワード検索を使えます。

## うまくいかないとき

意味検索には BGE-M3 が別途必要です。ソース開発には Node 22+ と uv が必要です。[開発手順](../../DESKTOP.md#source-development)を参照してください。

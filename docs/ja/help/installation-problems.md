# インストールや起動の問題を解決する

## できること

非対応環境・OS の拒否・旧プロセス・読み込み失敗を切り分けます。

## 始める前に

アプリと OS の版、入手元、機密部分を除いたエラーを記録します。

## 操作手順

1. 対応 OS と CPU、パッケージを確認します。
2. 拒否されたら公式 Release の出所と具体的な理由を確認し、全体の保護は維持します。
3. 旧インスタンスをトレイから終了して再起動します。
4. ページ更新は Python・Electron を更新しません。ソース変更後は再起動します。
5. 一般設定からログフォルダーを開き、最初の起動エラーを記録します。

## 完了後の状態

インストール・ポート競合・バックエンド版・UI のどこで失敗したか確認できます。

## うまくいかないとき

白紙画面の対処として資料・モデル・認証情報・履歴を消さないでください。続く場合は再現手順と脱敏ログを添えます。

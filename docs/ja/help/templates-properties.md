# テンプレート・日記・プロパティを使う

## できること

メモの構造を再利用し、プロパティで整理します。

## 始める前に

保管庫ルートからの相対パスでテンプレートと日記のフォルダーを用意します。

## 操作手順

1. 設定のテンプレートと日記でパスを保存します。
2. テンプレートから新規メモを作るか、今日のメモを開きます。既存の日記は保持されます。
3. YAML プロパティを確認・編集し、必要ならソースを開きます。
4. `status`・`tags`・`due` などの項目を統一します。

```yaml
---
title: Reading notes
tags: [reading]
status: open
---
```

## 完了後の状態

プロパティは Markdown 内に保存されます。テンプレートは既存メモを継続同期しません。

## うまくいかないとき

同名がある場合は別の名前を選び、型を統一して不明な項目を残します。

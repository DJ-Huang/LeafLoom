# LeafLoom 0.1.7 — ワークハブと安定したアセット情報取得

バージョン日付：2026-11-02 · v0.1.6 以降の変更

[English](../en/RELEASE_NOTES_0.1.7.md) · [中文](../zh-CN/RELEASE_NOTES_0.1.7.md) · [日本語](RELEASE_NOTES_0.1.7.md)

## プロジェクトをまたぐ作業記録

**設定 → Skill** で `work-hub` をインストール・更新し、AI アシスタントで作業記録、プロジェクト関連付け、ローカルタスク、レポートを管理できます。記録と原文は現在の知識庫に保存します。レポートは根拠と明示された実績工数を使い、個人の編集や週報テンプレートを保持します。オフィス製品への接続は任意です。

## オフィス製品を複数選択

設定画面とチャットは、バージョン保護付きの設定ノートを共用します。複数の製品、自動選択、ローカルのみを選べ、旧単一選択も読み取れます。飛書の資料・タスク同期と指定した GitLab 活動の取得に対応します。DingTalk・WeCom・Notion は設定の保存のみで未連携と表示します。選択だけで取得範囲や外部書き込みの許可は増えません。

## 飛書ページを必要時に保存

指定ページと子ページを読みやすい作業フォルダーに同期します。画像・動画は添付サーバーへストリーミングし、サイズとハッシュの確認後に参照を置換します。進捗、ローカル編集、元ページが削除された際のコピーを保持します。本機の LeafLoom、Python 3.11+、認証済み lark-cli と添付サーバーが必要です。

## Unity 商品情報の取得を制御

添付グループのプレビュー、件数制限、取得間隔、既存商品の不足情報の補完に対応します。公式情報の読み取りは最大 3 並列で、制限やアクセス確認時に新規要求を止め、再開用の進捗を保持します。一時障害の再試行と空検索結果に対応し、既知の情報や個人の整理を消しません。ローカル投影と WebDAV 確認の全体読み取りも削減します。有料パッケージの取得や Unity への自動インポートは行いません。

## 操作とサーバーの案内

上部パスバーから相対・絶対パスをコピーでき、キーボードと結果表示にも対応します。DUFS の三言語設定・分離ガイドに再現可能なリンク隔離パッチと検証手順を追加しました。ユーザーファイルやサーバーアカウントを自動変更しません。

## 更新と提供状況

知識庫とメタデータをバックアップし、LeafLoom を終了して対応パッケージをインストール後、同じ知識庫を開きます。ソース利用者は更新して再起動してください。ワークハブ Skill は設定画面で別途更新し、AI クライアントの技能一覧も更新します。既存記録の一括移行はありません。

対象は Windows x64 と macOS 14+ Apple Silicon。Windows は未署名、macOS は ad-hoc 署名で Apple 公証はありません。実際の提供状況は Release のインストーラー、SHA256SUMS.txt、ネイティブビルド記録を参照してください。すべての端末やオフィス接続の検証を保証しません。

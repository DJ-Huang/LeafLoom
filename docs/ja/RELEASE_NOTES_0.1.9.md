# LeafLoom 0.1.9 - カレンダー、統合スキル、添付ファイルの高速化

公開日：2026-11-12 · v0.1.8 からの変更

[English](../en/RELEASE_NOTES_0.1.9.md) · [中文](../zh-CN/RELEASE_NOTES_0.1.9.md) · [日本語](RELEASE_NOTES_0.1.9.md)

## カレンダーで予定を管理

月・日・予定一覧の各表示で、共有の日次ノート、繰り返し予定、データベースのタスクを利用できます。カレンダーファイルは保管庫を通じて同期され、競合の処理、削除の復元、検証済みバックアップを伴う移行に対応します。通知設定と配信履歴は端末ごとに保持されます。ファイル同期では引き続き `.vault-rag` を除外してください。

Windows の旧カレンダー移行で起きるバックアップのフラッシュ失敗も修正し、検証済みバックアップとカレンダーデータを保持します。

## 一つにまとまった LeafLoom スキル

インストール可能なスキルに、ローカル検索、タスク、作業記録、Design Studio の操作を統合しました。作業は構造化された活動と読みやすい期間ログの両方に記録され、工数が未指定なら保存前に確認します。週報は管理者向けの簡潔な Markdown を標準とします。置き換えられた旧スキルは、ローカルにバックアップを残して無効化します。

Windows の新しい PowerShell エントリーポイントは Python 3.11+ を選択し、Unicode、引用符、パス、入れ子の JSON 引数を手動のエスケープなしで保持します。Microsoft Store エイリアスを避け、書き込み失敗時に自動再試行しません。

## 添付ファイルの待ち時間を短縮

ローカルとサーバーを独立して読み込み、サーバーが利用できなくてもローカルファイル、絞り込み、ページ位置を保持します。アプリが管理するサーバーカタログにより、ディレクトリ全体の走査を減らします。ノートに貼り付けた小さな画像は保管庫のローカルキャッシュに保持でき、大きなファイルには軽量プレビューを使います。有効なキャッシュをすぐ開き、サーバーの版はバックグラウンドで確認します。サーバー移行は中断からの再開、分割処理、転送・検証の進捗表示に対応します。HTML と Design Studio の素材は各プロジェクトフォルダー内に保持します。

ノート画像を右クリックメニューや Ctrl/Cmd+C で PNG としてコピーできます。画像操作を一つのメニューにまとめ、ブラウザーのクリップボード API が使えない場合のパスコピーも修正しました。

添付の参照同期がメンバーシップカタログ内の子レコードを参照として扱う問題を修正。移行再開時は確認済みのマッピング・後処理段階を保持し、検証済み転送の再アップロードを避けます。元のパスでローカルファイルが変更されていた場合は、削除せず停止します。

## Design Studio と公開

プレビュー、比較、プレゼンテーションで公開サイトへのリンクを使えます。有効な外部ソース編集は、一回で元に戻せる変更として取り込まれます。Miaoda 公開では一時的な状態取得エラーやアップロード中断からの復旧を改善し、読み込みと再試行の挙動を明確にしました。

## 更新と対応環境

保管庫とメタデータをバックアップし、LeafLoom を終了して対応するパッケージをインストール後、同じ保管庫を開いてください。ソース版は更新後に再起動してください。インストーラーは Windows x64 と macOS 14+ Apple Silicon 向けです。Windows は未署名、macOS はアドホック署名で Apple の公証はありません。インストール前にこの版の配布ファイル、SHA256SUMS.txt、ビルド結果を確認してください。

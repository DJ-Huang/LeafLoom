## ローカルとサーバーの添付をまとめて閲覧

**設定 → 添付サーバー** にアドレス、アカウント、パスワードを入力して、汎用 WebDAV または SMB2/3 に接続します。新しい添付の保存先を変えても既存ファイルや資料ライブラリの紐付けは変わりません。ノートはローカルに保存し、サーバーの原本は必要時に読み込み・取得します。

一覧には簡潔なツールバー、必要時に開く概要、折りたたみ式情報欄、直接表示できない形式の既存表紙プレビューを用意しました。保存元、ディレクトリ、形式、分類、タグや手動選択でグループを管理できます。切り替え時は見出し・一覧・件数を更新し、失敗しても前の内容を新しいタブに残しません。**ダウンロード** は独立ページ、作成とインポートはディレクトリ操作へ移動しました。

## 自動同期と中断からの再開

再接続後に一覧を自動確認し、完了から五分後に再確認します。完了したディレクトリを端末に保存し、通信中断や再起動後に再利用します。次回以降は10 分以内のキャッシュを使い、期限切れの子を個別に確認します。**同期状況** は進捗、再利用数、再接続と同期の現在状態を示し、一時的な問題は詳細へ折りたたみます。認証失敗時は情報の更新が必要です。

変更履歴を提供しないサーバーでは定期照合が必要です。更新後の初回は再開位置を作成し、即時の変更ストリームではありません。未完了の走査では既存記録を保持します。移行・整理の入口は非表示ですが、過去のタスクと復旧資料を残します。

## AI に使わせる素材範囲を選ぶ

対象グループの **AI 素材検索の対象にする** を有効にすると、その範囲の情報検索、既存プレビュー、検証済み原本のローカル保存先への受け渡しができます。任意のローカル意味検索はノート検索と分離し、未選択では全体へ検索を広げません。Unity への自動インポートや購入権限の確認は含みません。

既存 Unity パッケージの公式製品情報、複数版、個人タグ、実際の表紙を保持します。任意の公式情報取得は製品の識別を確認し、個人編集を保って一括処理を再開できます。グループ・参照・資料は検証したサーバー記録で同期し、競合を明示します。使用中の SQLite は端末に置きます。

## Design Studio の発表と AI 操作

全画面プレビューは画面の縦横比と現在の操作を保持します。デスクトップの発表者モードは独立した観客画面、操作プレビュー、非公開ノート、ステップ移動、ブラックアウトと再接続に対応。ノートは履歴に残し、観客用文書と書き出しから除外します。

Design MCP はページ分割した要約とページ・要素・素材の指定読み取り、簡潔な編集結果に対応しました。サーバー側の素材取り込みで大きなデータの往復を減らします。ノートと履歴の保存後は先に結果を返し、資料更新は裏で進めることで保存応答の相互待機を修正しました。

## 更新と互換性

1. 保管庫をバックアップし、アプリの資料、送信待ち、復旧ファイルを保持します。完全終了後にアプリを置き換えてください。
2. 対象 OS のパッケージをインストールして同じ保管庫を開き、認証情報の復元と最初の走査を待ちます。既存 ID、ルート、送信先と資料の紐付けは保持します。
3. 更新後は MCP クライアントのツール一覧も更新します。ソース版はコードを更新して **LeafLoom を再起動** してください。Dev とインストール版は同じ設定を使います。

インストーラーは Windows x64 と macOS 14+ Apple Silicon 向けです。Windows は未署名、macOS はアドホック署名で Apple の公証なしです。`SHA256SUMS.txt` とネイティブビルドの記録を確認してください。CI はすべての NAS、VPN、実機画面構成を保証しません。Windows の発表実機検証は別途記録します。

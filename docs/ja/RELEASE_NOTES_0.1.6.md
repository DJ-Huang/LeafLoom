# LeafLoom 0.1.6 — ノートデータベースと統一ワークスペース

## 一つのノート集を五つのビューで

Markdown ノートを表・リスト・ボード・ギャラリー・タイムラインで整理できます。各レコードは通常のノートのまま、本文・添付・属性は既存エディターとファイル履歴を使用します。ビューごとにフィルター・並べ替え・グループ・レイアウトを保存し、固定ビューを他のノートに埋め込めます。新規レコードには、現在のビューの明確で互換性のある等値条件を自動入力します。

レコードメニューからサイド表示・全ページ表示・名前変更・複製・リンクコピー・復元可能なごみ箱移動を行えます。詳細では主要項目を表示し、その他は折りたたみます。下部で項目を追加し、項目メニューで名前・順序・定義・単一／複数選択の表示名や色を編集できます。定義や選択肢を削除しても元ノートの値と本文は保持します。

## ボードで基本タスクを管理

タスクプリセットは状態・優先度・期限を明示的に関連付けます。列をまたぐ移動、列内の手動順序、取り消しと版チェックに対応します。グループ・色・カード項目を設定でき、グループ削除時は対象記録と移動先、必要な状態の引き継ぎを確認します。

連続ドラッグの停止、新規作成・移動・削除の表示遅延、メタデータ準備中の再試行を修正しました。従来のタスクボードとカレンダーも利用できます。

## ワークスペースの統一

サイドバー・ホーム・エディター・データベース・添付・グラフ・Design Studio・ダイアログの文字、余白、フォーカスを統一し、小画面にも対応します。Design Studio はページ一覧の複製／削除、選択ページの HTML 出力、Publish to から新規または関連付け済み Miaoda コースアプリへの公開に対応します。

## 添付同期を制御

拡張子の許可リストをローカル・サーバー閲覧とアップロードで共有します。サーバーの走査対象、一時停止／再開、同期段階を確認できます。起動時は保存済み一覧と確認時刻を再利用し、約30分ごとに確認します。元ファイル・既存リンク・未送信資料は保持します。

## データベースの MCP 操作

更新後は MCP ツール一覧を再読み込みしてください。型付きコマンド、機能説明、本文の分割読込、項目・ビュー設定、ビュー順序、グループ管理、カード移動・取り消しを提供します。読み取り専用権限、ファイル境界、版チェック、再試行 ID を維持します。データベース閲覧はノート検索の対象を広げません。

## 更新と対応環境

保管庫をバックアップし、メタデータと復旧ファイルを保持してください。アプリを完全終了して対応するインストーラーで更新し、同じ保管庫を開きます。ソース利用時は更新後に LeafLoom を再起動します。

Windows x64 と macOS 14+ Apple Silicon に対応します。Windows は未署名、macOS はアドホック署名で Apple 公証はありません。SHA256SUMS.txt と関連するネイティブ実行記録を確認してください。CI は全端末・サーバー・物理ディスプレイ構成での検証を意味しません。

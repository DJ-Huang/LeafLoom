## デザインの整理と比較

ページを折りたたみ式フォルダーに分類し、複数ページの移動、フォルダーの改名・統合、分類解除ができます。レイヤーとプロパティのパネルは個別に折りたためます。**比較**モードでは左で編集し、右の操作可能なプレビューを保存後に更新します。

## 元画像と要素の位置情報をコピー

単一の元画像を元のサイズと透明背景のまま PNG としてコピーできます。バインディングとバリアントにも対応し、プロジェクトは変更しません。Cmd+C／Ctrl+C、コンテキストメニューまたはプロパティパネルから単一・複数要素の簡潔な位置情報をコピーできます。文字やソースの通常のコピーも引き続き利用できます。更新後は LeafLoom を再起動して新しいデスクトップのクリップボード機能を利用してください。

## Markdown メモを移動

新しい折りたたみ式の目次は現在の節を表示し、見出し階層の開閉、本文・ソースでの移動、編集への追従に対応します。狭い領域では重ねて表示します。

## 添付ファイル同期の効率化

ディレクトリの確認間隔を使用状況に応じて調整し、アップロード後は関連先を確認します。変更のない資料・グループの取得と失敗時の再試行は間隔を延ばし、再起動後も予定を保持します。外部で削除されたキャッシュ済みディレクトリからも復帰できます。手動の全確認はすぐに実行します。

## 更新と対応環境

保管庫とメタデータをバックアップし、LeafLoom を終了して対応パッケージをインストールした後、同じ保管庫を開いてください。ソース利用者は更新後に再起動してください。インストーラーは Windows x64 と macOS 14+ Apple Silicon 向けです。Windows は未署名、macOS はアドホック署名で Apple の公証はありません。このバージョンの添付ファイル、SHA256SUMS.txt とビルド結果を確認してください。

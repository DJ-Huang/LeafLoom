# 変更履歴

[English](../../CHANGELOG.md) · [中文](../zh-CN/CHANGELOG.md) · [日本語](CHANGELOG.md)

## 未リリース — 2026-10-16

- 非公開設定、認証情報、ローカル状態の除外を強化。公開著者名を保持し、履歴の個人パスと非公開コミットメールを匿名化。

- HTTP MCP を 23 ツールに拡張。全フォルダーの検索、Markdown/TXT/HTML 編集、プロパティ、フォルダー、参照を更新する移動、ゴミ箱、履歴復元、テンプレート、日記、索引同期に対応。
- ローカルと ChatGPT に独立した MCP 認証情報と書き込み設定を追加。初期状態は読み取り専用とし、従来の検索範囲と内蔵アシスタントの提案フローを維持。
- ワークスペース・ファイル・操作のバージョンを検証し、BOM と改行を保持。移動失敗のロールバックでも外部の変更を保護。

## 0.1.1 — 2026-10-15

- Secure MCP Tunnel の設定、認証情報の暗号化保存、接続ライフサイクル管理を内蔵。
- ノート編集を改善し、多言語の入門サンプルを追加。
- macOS Apple Silicon インストーラーを公開。0.1.0 と同様、署名・公証なし。
- HTML プロジェクトにリソースルート、SPA ルーティング、独立した永続オリジン、移動とダウンロードを追加。既存の HTTP/HTTPS サイトや開発サーバーも開けます。
- 旧ループバックアドレスから下書きと表示状態を移行し、競合時は復元用バックアップを保持。macOS 14/15 Safari 専用の互換性設定を追加。
- 整形された Markdown を直接編集。スラッシュコマンド、ブロック移動、表、リンク、数式、図、貼り付けやドロップによる添付に対応。
- 本文とソースで元に戻す履歴を共有し、未変更の原文とプロパティを保持。保存の競合時も下書きを残します。

## 0.1.0

- LeafLoom のブランド、書籍とつながりのロゴ、ウェブ・デスクトップのアイコン。
- 中文・English・日本語の画面、共通デスクトップ文言、独立した言語設定。
- 3 言語の架空のデモ、明示的な検索範囲、再開可能なチェックリスト。
- 既存の設定と識別子を保持。言語変更で索引を再構築しません。
- キーワード検索の分割を日本語のかなに対応。
- 多言語ガイド、コミュニティ文書、匿名化した画像、英語の紹介動画。

macOS のメニューは更新したソースから再ビルドしてください。専用のワークフローを用意しています。環境の検証記録はリリースノートと分けて記載します。

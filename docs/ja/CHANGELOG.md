# 変更履歴

[English](../../CHANGELOG.md) · [中文](../zh-CN/CHANGELOG.md) · [日本語](CHANGELOG.md)

## 未リリース

- Markdown の 5 色ハイライト、行内・ページコメント、返信・編集、解決・再オープン、コメントパネルとソースモードの注釈表示を追加。独立した SQLite にユーザーデータを保存し、ノート移動・削除・復元や MCP 経由の操作でも関連付けを保持。権限付き MCP コメントツールを提供。

- アプリとトレイのメニューに **LeafLoom を再起動** を追加。下書きの確認とバックエンドの正常終了を維持し、Dev は Vite を保ったまま Python 依存関係を同期してソースを開き直します。未保存の確認で戻ると再起動をキャンセルします。

- 添付ダイアログを専用のグリッド／一覧画面に更新。全体の名前・パス検索、絞り込み、並べ替え、メディアのインライン表示、一度の初期設定、明確な進捗、同名を保持するアップロード、参照確認と復元付きの名前変更・移動・回収、非同期 ZIP ダウンロードに対応。制作素材は読み取り専用とし、狭い画面にも対応。

- 添付の移行で HTML・ソースプロジェクトと共有素材を保持し、リテラルのフォルダー・設定参照も保護。制作バイナリをテキストとして誤判定せず、独立した添付は変更検知とロールバックを保って移行。

- 添付の移行プレビューのブロックと索引の初期化を区別し、主なブロック理由を翻訳。ブロック・除外一覧に表示件数と総件数を表示。

- macOS の開発モードで Dock のアイコンと名前を修正。Dev はブランド設定済みのランタイムをキャッシュし、LeafLoom のロゴと名前を表示します。

- 添付索引の初期化・更新と保存先の移行を一つのフローに統合。索引の自動準備とプレビュー後、一度の確認でコピー、参照更新、元ファイルの復元用保管、最終索引の再構築を実行。索引のみの保守は折りたたまれた詳細設定に配置。画面を開くだけでは読み取りのみ行い、HTML プロジェクトは移行対象外。

- 明示的な確認が必要な非同期添付移行プレビューを追加。進捗の保存、安全上のブロック、停止、記録からの復旧、確認付きロールバックに対応。元の添付とノートのバックアップを保持し、完了後のアップロード先を統一。

- メタデータのみの SQLite 添付索引とサイドバーの添付管理を追加。名前／パスのページ検索、元ファイルのダウンロード、更新、キャンセル、再試行に対応。元ファイル、HTML プロジェクト、既存 URL は変更しません。

- 正式 Release の公開時に重複して Pages がデプロイされる問題を修正。最新 Release API の反映が遅れている場合は再試行し、古いダウンロードリンクの再公開を防止します。

## 0.1.3 — 2026-10-18

- デザインワークベンチの階層とページ操作を整理し、一括公開に固定操作バー・出力概要・展開可能な結果を追加。3 つの編集可能なアートボードと英語・中国語・日本語バリアントを備えた ATELIER 照明テンプレートを追加。

- 安定したテキスト・画像データの関連付け、再確認可能な言語・汎用バリアント、レイアウト上書き、文字・素材の事前チェックと範囲付きフィットを追加。ページとバリアントを選んで PNG ZIP または複数ページ PDF を進捗表示・再試行付きで書き出せます。インタラクティブな HTML 出力と元に戻す・競合保護を維持。

- 編集 / プレビュー切替を追加。パネルのない画面でページ切替と再生を試せます。最新の変更を保存してから開始し、保存失敗時は変更を保持。戻ると元のページ、選択レイヤー、キャンバス位置を復元します。

- 編集可能なネイティブアニメーションと JavaScript の例を備えた Motion Playground テンプレートを追加。タッチ用レイアウトとガイドを同梱し、視差効果低減の変更、フォーカス／タッチに対応。繰り返し操作によるアニメーションの蓄積を防止。

- デザインスタジオの日常操作を改善。範囲選択、スナップガイド、矢印キー移動、実際の描画座標による整列と等間隔配置、複数選択の拡縮、自動レイアウト内の並べ替えを追加。サイズ、文字組み、効果、画像切り抜き、リンクされた共通スタイル、コンポーネントの上書きとリセットを視覚的に編集でき、変換の制約と未保存変更の復旧を明示。カード作成、FORMA のブランド変更、編集した HTML の ZIP 再表示を検証対象に追加。

- Design Studio でフォルダー選択時に意図せず作成される問題を修正。空白・FORMA とも明示的な作成操作を必須にし、親フォルダーと作成先の表示、名前検証、重複クリック防止を追加。

- 新規デザインプロジェクトにプレビュー付きの FORMA エディトリアルスタジオテンプレートを追加。4 つの編集可能アートボードと 328 レイヤーを同梱し、各コピーの履歴を独立させて既存フォルダーの上書きを防ぎます。

- Design Studio の操作性を改善。パンとズームを保持し、選択・手のひらツール、ページ・選択範囲へのフィット、折りたたみ可能なレイヤー、選択パス、分類されたプロパティを追加。キャンバス接続失敗時に再試行を表示。変換時に HTML の文書コンテキスト、混在テキスト、レスポンシブリソースをより忠実に保持し、元のソースとプレビューの分離を維持。

- デザインプロジェクトのゴミ箱に完全削除と全削除を追加。確認、バージョン検証、中断後の再開に対応し、関連する復元記録を削除しながら他の履歴と共有ライブラリを保持します。

- 新しいプロジェクトホームが古いバックエンドに接続した際の Not Found と削除の無反応を修正。再起動の案内と再試行を表示し、管理状態を取得するまで関連操作を無効にします。
- 公式サイトの 3 言語のトップページに既存の英語デモ動画を追加。標準の再生操作、各言語のスクリーンショットのポスター、動画への直接リンクを用意。

- 明示的に分離した状態ディレクトリと Vite を使う、任意のブラウザー開発用起動スクリプトを追加。`--loopback-ui` の指定で管理画面に `localhost` を使い、認証と HTML プロジェクトの別オリジンを維持しながら管理対象ブラウザーとの互換性を改善します。プロジェクトのプレビューには制限が残る場合があります。通常のデスクトップ起動とインストーラーの対応環境は変更しません。

- バージョンと一致するタグの push で、GitHub が Windows x64 / Mac arm64 インストーラーと検証済み SHA-256 ファイルを Release 下書きに作成。公開は手動で行い、公開済み版の上書きを防止。手動の添付ファイルのみのビルドも維持し、証明書なしの Mac ビルドは公証なしの ad-hoc 署名を使用。

- 設定のサイドバー項目とページタイトルを「AI 連携」から「Skill」に変更。

- 公式サイトに日英中の作者紹介ページを追加し、GitHub と X のプロフィールをナビゲーションとフッターから案内。

- 公式サイトで Windows / Mac ごとに利用可能な最新正式版と対応するバージョン・ノート・チェックサムを掲載。Pages 環境で `v*` タグを許可し、Release イベントからの自動公開に対応。

- デザインスタジオを HTML ゲーム画面のビジュアル作業環境へ拡張。プロジェクトホームとゴミ箱、素材情報と置換、再利用コンポーネントと埋め込みページ、バージョン付き個人共有ライブラリ、独立 ZIP 書き出しに対応。従来の 1.1.0 は維持し、DOM/CSS を別コピーへ変換し、認識できるナビゲーション、スイッチ、入口に応じたページ状態を引き継ぎます。元スクリプトはコピーしたソースに残り、その他の実行時動作には新しいスクリプトが必要です。

- ページ、ソース、素材、直接適用する AI 一括編集に共通の永続トランザクション履歴を追加し、再起動後も元に戻す/やり直しに対応。バージョン確認、冪等な再試行、保留中の保存復元、外部変更の保護を実装。アニメーションプリセットと要素/ページごとの `mount(ctx)`、編集可能なパラメーター、分離プレビュー、リソース解放、ログを提供。ドラッグは選択要素のみをフレーム更新し、終了時に一度コミットします。実プロジェクトと負荷例の性能予算は明示的な検証目標です。

- 統合後の HTTP MCP は、23 のノートツール、14 のデザインスタジオツール、5 つの任意の Feishu ツールを含む計 42 ツールを提供。ノートと Feishu の権限は独立して維持します。更新後はツール一覧を更新し、管理されたデザインには文書、一括操作、履歴、素材、共有ライブラリ、書き出しの各 API を使用します。

## 0.1.2 — 2026-10-16

- Feishu 文書／Base 用の四つの個別ツールを、インストール済み lark-cli の動的検索・汎用読み書き・認証単位の添付転送に置き換えました。XML ブロック編集とリビジョン事前確認に対応し、ローカル／Tunnel 別の高リスク許可と操作ごとの明示的確認を追加しました。更新後はクライアントのツール一覧を更新してください。

- Dev とインストール版の Tunnel 起動・終了を統一。既存インストールの実行ファイルを再利用し、共有ディレクトリごとに 1 インスタンスを許可し、終了時に子プロセスを回収します。MCP 認証エラーと Feishu の不正なテーブル参照を区別します。

- 同じ Tunnel を使う ChatGPT 会話間で MCP 権限が異なる問題を修正。ランタイム専用認証ヘッダーで接続側の Authorization との衝突を防ぎ、リソース権限と即時失効を維持します。

- 外部でインストール・設定・ログインした lark-cli による任意の Feishu/Lark 連携を追加。アカウント検証と汎用 CLI MCP ブリッジに対応。ローカルと Tunnel の Feishu 権限をノート権限から分離し、認証情報は CLI が管理、文書編集には読み取り時のリビジョンを使用。
- CLI のページング情報を保持し、文書の書き込み前にリビジョン変更を拒否。上流のリビジョン引数はクライアント間の原子的な編集保護を提供しません。

- 設定 → 一般にアプリ更新を追加。現在と最新のバージョン、検証付きダウンロード、進捗バー、通常終了後のインストーラー起動に対応。macOS は DMG を開き、ソース Dev は確認のみ。

- Dev とインストール版のユーザーデータ保存先、設定、モデル、AI/MCP 認証情報、デスクトッププロファイルとポートを統一。開発依存関係は分離し、共有モデルフォルダーが未作成の場合は旧 Dev モデルを安全に再利用。

- モデル設定と初回ガイドに実際の保存先と「フォルダーを開く」を追加。初回ダウンロード前も空のフォルダーを確認可能。

- 検索設定と初回ガイドにモデル準備の段階、受信量と速度、経過時間、待機案内、失敗詳細と再試行を追加。準備の重複、10 分でのダウンロード待機タイムアウト、重みの重複検証を回避。

- GitHub Pages に日英中のレスポンシブな製品サイトを追加。実際の製品画面、最新正式版の Windows / Mac 直接ダウンロード、リリースノートとチェックサムを掲載。関連する main の更新と Release イベントで再公開します。

- 非公開設定、認証情報、ローカル状態の除外を強化。公開著者名を保持し、履歴の個人パスと非公開コミットメールを匿名化。

- 従来のリポジトリ起動スクリプトを削除。インストール済みアプリは直接管理し、ソース開発には Dev を使用。

- Windows の `Dev.cmd` と Mac の `Dev.command` / `Dev.sh` によるソースからのデスクトップ起動、フロントエンドの自動更新、専用 Python 環境とインストール版と共有するユーザー設定を追加。

- HTTP MCP を 23 ツールに拡張。全フォルダーの検索、Markdown/TXT/HTML 編集、プロパティ、フォルダー、参照を更新する移動、ゴミ箱、履歴復元、テンプレート、日記、索引同期に対応。
- ローカルと ChatGPT に独立した MCP 認証情報と書き込み設定を追加。初期状態は読み取り専用とし、従来の検索範囲と内蔵アシスタントの提案フローを維持。
- ワークスペース・ファイル・操作のバージョンを検証し、BOM と改行を保持。移動失敗のロールバックでも外部の変更を保護。

## 0.1.1 — 2026-10-15

- Secure MCP Tunnel の設定、認証情報の暗号化保存、接続ライフサイクル管理を内蔵。
- ノート編集を改善し、多言語の入門サンプルを追加。
- macOS Apple Silicon インストーラーを公開。0.1.0 と同様、署名・公証なし。
- HTML プロジェクトにリソースルート、SPA ルーティング、独立した永続オリジン、移動とダウンロードを追加。既存の HTTP/HTTPS サイトや開発サーバーも開けます。
- 旧ループバックアドレスから下書きと表示状態を移行し、競合時は復元用バックアップを保持。macOS 14/15 Safari 専用の互換性設定を追加。
- 整形された Markdown を直接編集。スラッシュコマンド、ブロック移動、表、リンク、数式、図、貼り付けやドロップによる添付に対応。
- 本文とソースで元に戻す履歴を共有し、未変更の原文とプロパティを保持。保存の競合時も下書きを残します。

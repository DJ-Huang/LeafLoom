# 変更履歴

[English](../../CHANGELOG.md) · [中文](../zh-CN/CHANGELOG.md) · [日本語](CHANGELOG.md)

## 未リリース

- 添付グループを切り替えても内容が変わらないように見える問題を修正。見出しと読み込み状態を即時更新し、明示的な絞り込みでは前の一覧を消し、失敗時は再試行を表示。索引の進捗による読み込みの繰り返し中断を防止。

- 接続復旧後も過去の同期エラーが残る問題を修正。再接続と資料同期の現在状態を表示し、一時的な接続問題は自動再試行の詳細へ折りたたみます。最終成功時刻を保持し、復旧時に資料同期を起こします。認証など対処が必要なエラーは保持します。

- 添付ディレクトリの走査位置を端末に保存し、通信中断や再起動後に再開。差分確認では有効な一覧を再利用し、一台につき二ディレクトリまで同時に読みます。期限切れの子を個別に確認し、変更のない記録の書き直しを抑制。再利用数と原本を取得しない全確認操作を追加。

- 添付ツールバーに走査済み・待機中の件数を表示。接続・応答タイムアウトと読み取り中断を翻訳して失敗時刻を保持し、機密情報を含む例外本文は表示しません。

- 自動走査通知で大きな添付一覧の読み込みが繰り返し中断される問題を修正。更新をまとめ、既存表示を保持し、タイムアウト時の再試行と仮想パスの重複確認削減に対応。

- 添付情報の折りたたみ、必要時のみ開く概要・同期状況、表紙プレビューで画面を簡素化。WebDAV に加えて汎用 SMB2/3 と自動一覧同期に対応し、作成と取り込みをディレクトリ操作へ移動。移行と整理の入口を非表示に。

- 公開 MCP と内蔵 AI のデザイン読み取りをページ分割済み要約に変更。ページ／要素／リソースの正確なソース、版を固定したページ取得、短い編集・取り消し・取り込み結果に対応。完全な文書の明示取得と Web エディターの動作は維持。版別の索引を再利用し、公開 MCP の JSON をワーカースレッドでコンパクトに変換して時間と文字数を記録します。

- サーバー添付のディレクトリ読み取りがタイムアウトした場合は最大 2 回再試行し、それでも失敗した場合は既存の記録を保持します。

- デスクトップに 2 画面の発表者モードを追加。独立した観客ウィンドウ、ライブ操作プレビュー、非公開ノート、ステップ／事例ナビゲーション、ブラックアウトと再接続に対応。ノートは履歴付きで保存し、観客出力とエクスポートから除外。

- Design Studio に全画面プレゼンテーションを追加。縦横比を保って画面に合わせ、フローティングのページ操作と Esc 終了に対応。ネイティブ全画面が使えない場合はウィンドウ全体に表示し、操作状態と元の編集位置を保持。

- ノート保存とバックグラウンドのカタログ・添付更新が相互待機し、保存結果がタイムアウトする問題を修正。ファイルと履歴の確定後に応答し、メタデータ更新はキューで処理します。後続の MCP と編集操作を妨げず、バージョン・権限検証を維持します。

- デザイン素材 MCP に、保管庫内ファイルと現在の認証情報に属する飛書一時ファイルからのサーバー側取り込みを追加。大きな Base64 要求と素材の往復転送を省き、短い結果も選択できます。既存の引数と既定の戻り値、ソース・内容検証、権限境界、取り消し履歴は維持します。

- 新規保存先の切替でも既存のローカル・サーバー添付を表示。端末の目録準備とサーバー閲覧を分離し、同名参照の誤解決と同期削除前の原本上書きを防止。オフライン・送信待ち・複数端末同期の境界を三言語で明記。

- サーバー選択時はサーバー添付目録を直接利用し、ローカル目録の準備と任意の整理を分離。添付 SQLite、設定、キャッシュ、キューを端末専用領域へ移し、旧状態をスナップショットで保持して更新。アップロード完了・原本解放前にサーバー参照を保存・検証し、他端末は SQLite 同期なしで旧パスと ID を復元。競合を明示し、旧参照同期を追加。

- Tailscale などのプライベート VPN が使用する `100.64.0.0/10` の数値共有アドレスを添付ストレージでサポート。既存のプライベート HTTP 設定と明示的な許可を維持し、パブリック HTTP は引き続き拒否します。

- メタデータディレクトリ項目を持たない旧添付サーバー設定を保存できない問題を修正。アドレス変更時も既定のディレクトリと既存の認証情報を保持し、サーバーエラーを防ぎます。

- 添付グループごとに選択する AI 素材検索範囲を追加し、NAS 同期に対応。未選択時は空の結果を返し、競合グループを除外。製品詳細にも範囲内のパッケージのみを表示します。

- AI 素材の統合検索、任意のローカル意味検索、実画像プレビュー、固定保存先への元ファイル受け渡しを追加。接続権限で分離したタスクの完了後、サービス端末の検証済みパスを返します。既存のダウンロードを維持し、プロジェクトへの組み込みは AI が行います。

- Unity Asset の互換性情報がオブジェクトの場合に、添付を選択すると添付画面全体がクラッシュする問題を修正。文字列・配列・オブジェクトと入れ子のデータに対応し、空の互換性情報は表示しません。
- 添付管理を汎用ファイル表示に統一し、独自グループタブ、手動・ルール指定、保管庫への保存と NAS 読み戻し検証同期、競合の明示的な解決に対応。既存の出典情報と公式カバーを保持し、固定の製品画面を廃止。独立したダウンロード画面で既存の添付・ZIP タスクを保持し、一時保存容量の設定を移動。MCP にグループ検索とリビジョン付き編集を追加。

- JSON-LD がない公式ページでも製品と発行者の識別情報を検証して取得。不完全または不一致の ID は引き続き拒否。
- 製品情報の同期でHTTP クライアントと検証済みディレクトリ確認を再利用し、重複要求を削減。公式転送では互換性のため個別接続を使用する場合あり。各項目の読み戻し検証を維持し、失敗項目は同期待ちで保持。小さな製品情報は最大四つまで並列同期し、依存関係・権限の検証を維持。大規模カタログの起動時・バックグラウンド確認で検証済みローカルイベントのバッチスナップショットを再利用し、重複するディスク読み取りを削減。識別情報・権限と未検証イベントの SHA 検証は保持。

- ローカル一括スクリプトで公式情報の取得開始・再開、保存済み進捗の監視、リビジョンを確認した中国語情報の部分更新に対応。個人フィールドを保持し、公式取得の成功と中国語整理の完了は分けて確認。中断後も完了済みの要確認判断を保持し、遮断・通信失敗は再試行。バックグラウンド同期は検証済み地点から待機送信を先に再開し、初回・明示的な同期は先に遠隔を確認。
- 通常終了でバックグラウンド確認が中断されても前回の同期結果を保持し、次回起動時の誤ったサービスエラー表示を防止。
- 製品カタログのトランザクション内権限確認で同じ接続を再利用し、大量の製品情報書き込み時のデータベースロックを修正。コミット前の確認は維持。

- 公式製品情報の取得に対応済みの macOS ローカル HTTP プロキシを再利用し、公式接続先・TLS・応答制限を維持してシステム設定は変更しません。再取得で中国語を保持し、元の事実が変わると更新待ちを表示。NAS 同期の通信待ち中もローカルの製品情報を照会できます。

- 既存 Unity パッケージの製品表示を追加し、公式／個人情報を分離。公式 URL の照合と明示的な取得進捗、複数バージョン、NAS 保存カタログ、独立した 20 GiB の検証付きダウンロード一時保存に対応。Unity 自動インポート・購入権限の検証は対象外。

- 保存済み添付認証情報をバックグラウンドで復元し、対応する非同期システム暗号化 API を優先して起動待ちを避けます。再試行をまとめ、終了した接続への遅延結果を破棄します。

- サーバーの各ディレクトリに `leafloom.ignore` を置き、先頭行 `# leafloom-ignore v1` を必須として、Gitignore 形式のパターン・子ルールの上書き・`!` の再包含に対応。更新成功時に除外数を表示して添付の検索・集計から外し、ID・タグ・旧参照・キャッシュは保持。ルール取得に NAS の書き込み権限は不要。

- 添付画面からサーバーを明示してディレクトリを更新し、メタデータ同期の進捗と完了を表示。全体のスキャン成功後のみ NAS の欠落ファイルを一覧・容量から除外し、ID・タグ・旧参照を保持。失敗時は既存の記録を維持。

- 添付の容量表示をローカルとサーバーの原本サイズに分離。保存先を絞ると対象範囲のみを表示し、ローカルキャッシュは集計対象外に。

- 添付の認証復元に 1・3・10・30 秒の有限再試行、ロック解除・スリープ復帰時の再試行、設定の状態表示と手動復元を追加。NAS の接続障害・502–504 は 2–60 秒で再試行し、401／403 は同じ認証情報での自動試行を停止。正常性確認は設定済み URL のみとし、既存タスクの所有者・認証バージョン確認を維持。公式添付ウィンドウは開いたままにし、自動再構築には未対応。

- 添付の保存先フィルターを追加し、すべて・ローカル・サーバー・個別サーバーを切り替えて閲覧可能に。Web と MCP でサーバー側のフィルター、ページ、件数・容量・種類別の集計を共用。

- 汎用の複数 WebDAV サーバー設定、デスクトップのシステム暗号化認証情報、ブラウザーのメモリ内認証、容量制限付きキャッシュと独立したアップロード待機領域を追加。確認後のサーバー移行では読み戻し検証後に原本を解放し、LeafLoom 内の旧参照を維持。タグ・分類・説明の編集、原本とキャッシュ状態の表示に対応。公式クライアント経由では添付ウィンドウと転送ポートの維持が必要。

- 2 MiB 以下の通常添付を SHA-256 検証付き Base64 で一括送信可能に。画像アップロードの埋め込みリンクと、アップロード能力・クライアントツール一覧の更新案内を追加。既存の 2 ツール、分割転送、ChatGPT ファイル入力は維持。

## 0.1.4 — 2026-10-19

- 保管庫ルートの異なるパソコン間（Windows と Mac を含む）で同期したデザインを、別ディレクトリーのプロジェクトとして拒否する問題を修正。読み取り時は ID と履歴の所有情報を保持し、別フォルダーの重複 ID と内容の競合を検出しながら、同期後の移動・復元・ゴミ箱の整理にも対応。


- 書式ツールバーと選択範囲の右クリックメニューに **ハイライトを解除** を追加。選択範囲外の色とコメントを保持し、複数ハイライトの解除を一度で元に戻す／やり直すことが可能。

- ハイライト、コメント、返信、編集、解決／再オープン、再関連付け、削除の取り消しとやり直しに対応。本文・ソースと履歴を共有し、上部ボタンと同時変更の保護を追加。

- Markdown の 5 色ハイライト、行内・ページコメント、返信・編集、解決・再オープン、コメントパネルとソースモードの注釈表示を追加。独立した SQLite にユーザーデータを保存し、ノート移動・削除・復元や MCP 経由の操作でも関連付けを保持。権限付き MCP コメントツールを提供。
- 3 言語の公開ヘルプセンターを追加。各言語に 39 件のタスクガイドと 4 件の全体ガイド／更新資料を用意し、全文検索・分類・目次・前後の記事・画像拡大・例のコピーに対応。公式サイトとアプリから現在の言語へ移動し、文書変更も Pages で公開します。

- アプリとトレイのメニューに **LeafLoom を再起動** を追加。下書きの確認とバックエンドの正常終了を維持し、Dev は Vite を保ったまま Python 依存関係を同期してソースを開き直します。未保存の確認で戻ると再起動をキャンセルします。

- 添付ダイアログを専用のグリッド／一覧画面に更新。全体の名前・パス検索、絞り込み、並べ替え、メディアのインライン表示、一度の初期設定、明確な進捗、同名を保持するアップロード、参照確認と復元付きの名前変更・移動・回収、非同期 ZIP ダウンロードに対応。制作素材は読み取り専用とし、狭い画面にも対応。

- 添付の移行で HTML・ソースプロジェクトと共有素材を保持し、リテラルのフォルダー・設定参照も保護。制作バイナリをテキストとして誤判定せず、独立した添付は変更検知とロールバックを保って移行。

- 添付の移行プレビューのブロックと索引の初期化を区別し、主なブロック理由を翻訳。ブロック・除外一覧に表示件数と総件数を表示。

- macOS の開発モードで Dock のアイコンと名前を修正。Dev はブランド設定済みのランタイムをキャッシュし、LeafLoom のロゴと名前を表示します。

- 添付索引の初期化・更新と保存先の移行を一つのフローに統合。索引の自動準備とプレビュー後、一度の確認でコピー、参照更新、元ファイルの復元用保管、最終索引の再構築を実行。索引のみの保守は折りたたまれた詳細設定に配置。画面を開くだけでは読み取りのみ行い、HTML プロジェクトは移行対象外。

- 明示的な確認が必要な非同期添付移行プレビューを追加。進捗の保存、安全上のブロック、停止、記録からの復旧、確認付きロールバックに対応。元の添付とノートのバックアップを保持し、完了後のアップロード先を統一。

- メタデータのみの SQLite 添付索引とサイドバーの添付管理を追加。名前／パスのページ検索、元ファイルのダウンロード、更新、キャンセル、再試行に対応。元ファイル、HTML プロジェクト、既存 URL は変更しません。

- 正式 Release の公開時に重複して Pages がデプロイされる問題を修正。最新 Release API の反映が遅れている場合は再試行し、古いダウンロードリンクの再公開を防止します。

## 0.1.3 — 2026-10-18

- デザインワークベンチの階層とページ操作を整理し、一括公開に固定操作バー・出力概要・展開可能な結果を追加。3 つの編集可能なアートボードと英語・中国語・日本語バリアントを備えた ATELIER 照明テンプレートを追加。

- 安定したテキスト・画像データの関連付け、再確認可能な言語・汎用バリアント、レイアウト上書き、文字・素材の事前チェックと範囲付きフィットを追加。ページとバリアントを選んで PNG ZIP または複数ページ PDF を進捗表示・再試行付きで書き出せます。インタラクティブな HTML 出力と元に戻す・競合保護を維持。

- 編集 / プレビュー切替を追加。パネルのない画面でページ切替と再生を試せます。最新の変更を保存してから開始し、保存失敗時は変更を保持。戻ると元のページ、選択レイヤー、キャンバス位置を復元します。

- 編集可能なネイティブアニメーションと JavaScript の例を備えた Motion Playground テンプレートを追加。タッチ用レイアウトとガイドを同梱し、視差効果低減の変更、フォーカス／タッチに対応。繰り返し操作によるアニメーションの蓄積を防止。

- デザインスタジオの日常操作を改善。範囲選択、スナップガイド、矢印キー移動、実際の描画座標による整列と等間隔配置、複数選択の拡縮、自動レイアウト内の並べ替えを追加。サイズ、文字組み、効果、画像切り抜き、リンクされた共通スタイル、コンポーネントの上書きとリセットを視覚的に編集でき、変換の制約と未保存変更の復旧を明示。カード作成、FORMA のブランド変更、編集した HTML の ZIP 再表示を検証対象に追加。

- Design Studio でフォルダー選択時に意図せず作成される問題を修正。空白・FORMA とも明示的な作成操作を必須にし、親フォルダーと作成先の表示、名前検証、重複クリック防止を追加。

- 新規デザインプロジェクトにプレビュー付きの FORMA エディトリアルスタジオテンプレートを追加。4 つの編集可能アートボードと 328 レイヤーを同梱し、各コピーの履歴を独立させて既存フォルダーの上書きを防ぎます。

- Design Studio の操作性を改善。パンとズームを保持し、選択・手のひらツール、ページ・選択範囲へのフィット、折りたたみ可能なレイヤー、選択パス、分類されたプロパティを追加。キャンバス接続失敗時に再試行を表示。変換時に HTML の文書コンテキスト、混在テキスト、レスポンシブリソースをより忠実に保持し、元のソースとプレビューの分離を維持。

- デザインプロジェクトのゴミ箱に完全削除と全削除を追加。確認、バージョン検証、中断後の再開に対応し、関連する復元記録を削除しながら他の履歴と共有ライブラリを保持します。

- 新しいプロジェクトホームが古いバックエンドに接続した際の Not Found と削除の無反応を修正。再起動の案内と再試行を表示し、管理状態を取得するまで関連操作を無効にします。

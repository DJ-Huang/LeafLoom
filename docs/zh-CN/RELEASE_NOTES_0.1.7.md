# LeafLoom 0.1.7 — 工作中枢与更可靠的资源采集

版本日期：2026-11-02 · 自 v0.1.6 以来的变化

[English](../en/RELEASE_NOTES_0.1.7.md) · [中文](RELEASE_NOTES_0.1.7.md) · [日本語](../ja/RELEASE_NOTES_0.1.7.md)

## 跨项目记录工作

在 **设置 → Skill** 安装或更新 `work-hub`，在 AI 助手中记录工作、关联项目、管理本地任务和生成汇报。资料与原始依据保存在当前知识库。汇报采用有据事实和明确工时，保留个人编辑，并可使用自己的周报模板。无需连接办公平台即可使用这些能力。

## 同时选择多个办公软件

**工作中枢配置** 与对话共用一份带版本保护的配置笔记。可以多选平台，或使用按来源自动选择、仅本地模式；兼容已有单选配置。目前支持飞书资料与任务同步、指定 GitLab 活动采集；钉钉、企业微信和 Notion 仅保存偏好，标注尚未接入。选择平台不扩大采集范围或授权外部写回。

## 按需镜像飞书页面

将指定页面及子页面同步为可阅读的工作目录。图片和视频流式上传到附件服务器，大小和散列验证成功后才替换引用；断点保留进度、本地修改和源页面移除后的副本。此可选功能需要本机 LeafLoom、Python 3.11+、已登录的 lark-cli 和附件服务器。

## 更可控的 Unity 商品资料采集

支持按附件分组预览、限制数量、调整等待间隔及补齐已关联商品的缺失资料。官方读取最多三个并发请求；遇到限流或访问验证停止新请求并保留断点。临时故障可重试，空搜索结果正常处理，缺失资料不抹除已知事实或个人整理。本地目录投影和 WebDAV 目录检查减少不必要的全量读取，不下载付费原包或自动导入 Unity。

## 日常操作与服务器指引

顶部路径栏支持复制相对或绝对路径、键盘操作及剪贴板反馈。新增三语 DUFS 配置与隔离指南，提供可复现的符号链接补丁和验证脚本；不会自动迁移用户文件或修改服务器账号。

## 升级与可用性

先备份知识库及元数据，退出 LeafLoom，安装对应版本后打开原知识库。源码用户更新后重启；工作中枢 Skill 需在设置中单独更新，并刷新 AI 客户端的技能发现。已有工作资料不会批量迁移。

安装包面向 Windows x64 与 macOS 14+ Apple Silicon。Windows 未签名，macOS 使用 ad-hoc 签名、未经 Apple 公证。实际安装包、SHA256SUMS.txt 与原生构建记录以 Release 为准；文档不代表所有设备或办公接入已验收。

# LeafLoom 0.1.10 — 打开与分享设计项目

发布日期：2026-11-19 · 相比 v0.1.9 的变化

[English](../en/RELEASE_NOTES_0.1.10.md) · [中文](../zh-CN/RELEASE_NOTES_0.1.10.md) · [日本語](../ja/RELEASE_NOTES_0.1.10.md)

在设计工作台打开知识库外的已有项目，默认只读；需要保存修改时再启用编辑。从列表移除项目不会删除磁盘文件。

将项目导出为 ZIP 工程包，并在其他知识库中导入为独立副本，不会覆盖已有目录。

升级前备份知识库和元数据，退出 LeafLoom，安装对应版本后重新打开知识库。源码用户更新后需重启。Windows x64 安装包未签名；macOS 14+ Apple Silicon 安装包采用临时签名，未经 Apple 公证。安装前请核对发布附件、SHA256SUMS.txt 和构建结果。

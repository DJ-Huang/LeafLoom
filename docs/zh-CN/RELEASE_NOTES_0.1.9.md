# LeafLoom 0.1.9 - 日历、统一技能与更快的附件体验

发布日期：2026-11-12 · 自 v0.1.8 以来的更新

[English](../en/RELEASE_NOTES_0.1.9.md) · [中文](RELEASE_NOTES_0.1.9.md) · [日本語](../ja/RELEASE_NOTES_0.1.9.md)

## 用日历安排工作

在月、日和日程视图中使用共享日记、重复事项和数据库任务。日历文件随知识库同步，支持冲突处理、可恢复删除和带校验备份的迁移。提醒设置与发送记录保留在各设备上；文件同步时仍应排除 `.vault-rag`。

同时修复 Windows 旧日历迁移的备份刷新失败问题，保留经验证的备份与日历数据。

## 统一的 LeafLoom 技能

可安装技能整合本地搜索、任务、工作记录和设计工作室。工作记录同时写入结构化活动和人类可读的周期日志，未提供工时时先询问再保存。周报默认输出面向管理者的简明 Markdown。安装时停用已被替代的旧技能，并保留本地备份。

Windows 新增 PowerShell 入口，选择 Python 3.11+，无需手动转义即可保留 Unicode、引号、路径和嵌套 JSON 参数。它会避开 Microsoft Store 别名，写入失败时不会自动重试。

## 附件浏览更少等待

本地与服务器来源独立加载，服务器不可用时仍保留本地文件、筛选和分页。应用维护的服务器成员目录减少全目录扫描。粘贴到笔记的小尺寸图片可保留为知识库本地缓存，大文件则使用轻量预览。有效缓存立即打开，同时在后台检查服务器版本。服务器迁移支持断点续传、分批处理及传输和校验进度；HTML 与设计工作室资源仍保存在各自项目文件夹内。

通过右键菜单或 Ctrl/Cmd+C 将笔记图片复制为 PNG。图片操作统一到一个菜单中，路径栏也能在浏览器剪贴板 API 不可用时复制。

修复附件引用同步将成员目录子记录误当作引用记录的问题。恢复迁移时保留已确认的映射与清理阶段，避免重复上传已校验的传输；若原路径出现后续修改的本地文件，会停止而不删除该文件。

## 设计工作室与发布

预览、对比和演示模式支持公开网站链接。有效的外部源码编辑作为一个可撤销步骤导入。妙搭发布改进了临时状态读取失败和中断上传的恢复，并提供更明确的加载与重试行为。

## 升级与平台

先备份知识库及元数据，退出 LeafLoom，安装对应包后重新打开原知识库。源码用户更新后需重启 LeafLoom。安装包面向 Windows x64 与 macOS 14+ Apple Silicon。Windows 未签名；macOS 使用临时签名，未经过 Apple 公证。安装前请检查本版本的发布附件、SHA256SUMS.txt 和构建结果。

# LeafLoom 0.1.6 — 笔记数据库与统一工作区

## 一批笔记，五种数据库视图

将 Markdown 笔记组织成表格、列表、看板、画廊和时间线。每条记录仍是一篇笔记，正文、附件、属性沿用现有编辑器和文件历史。各视图独立保存筛选、排序、分组和布局，也可通过稳定视图引用嵌入其他笔记。新增记录会自动填写当前视图中兼容且明确的等值筛选条件。

记录右键菜单支持侧边预览、完整页面、重命名、复制、复制笔记链接和可恢复回收。详情默认展示精简属性，其余字段收起；底部可新增字段。字段菜单可直接重命名、排序、移除定义，以及编辑单选／多选选项的名称和颜色。删除字段定义或选项时，保留原笔记的值与正文。

## 用看板安排基础任务

任务预设显式绑定状态、优先级和截止日期。支持跨列移动、列内手动排序、撤销与版本保护，可配置分组、标签、颜色和卡片属性。删除分组会预览受影响记录，并选择迁移目标及必要的任务状态接替。

修复连续拖动失效、新增／移动／删除反馈延迟及元数据准备期间的重试问题。旧任务看板和日历继续保留。

## 一致的工作区体验

侧边栏、首页、编辑器、数据库、附件、关系图谱、设计工作台和弹窗统一字体、间距和焦点样式，兼顾窄屏。设计工作台新增页面列表复制／删除菜单、选定页面 HTML 导出，并可从“发布到”菜单将选定页面发布到新建或已关联的秒哒课程应用。

## 更可控的附件同步

附件后缀白名单统一作用于本地、服务器浏览及上传。可设置服务器扫描目录、暂停／恢复目录发现，并查看具体同步阶段。启动时复用已保存列表和检查时间，后台约每 30 分钟核对一次。原附件、已有链接和待提交资料保持保留。

## 完整的数据库 MCP 操作

升级后刷新 MCP 工具列表。数据库工具提供类型化命令、能力说明、正文分页读取、字段／视图配置、视图排序、分组管理和看板移动／撤销。只读授权、文件访问边界、版本与重试 ID 继续生效；浏览数据库不会扩大笔记检索范围。

## 升级与平台支持

请备份知识库并保留元数据及恢复文件。完全退出 LeafLoom，安装对应平台版本后打开原知识库。源码用户更新代码后使用“重启 LeafLoom”。

安装包面向 Windows x64 和 macOS 14+ Apple 芯片。Windows 未签名；macOS 使用临时签名，尚未经过 Apple 公证。请核验 SHA256SUMS.txt，并查看关联的原生构建报告。CI 不代表所有设备、服务器或实体显示器组合均已验证。

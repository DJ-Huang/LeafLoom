## 未发布

- 附件按来源独立加载，服务器目录不可用时保留本地结果的筛选与分页，全部附件统一按当前排序。预览立即使用有效的本地文件及分段缓存，服务器版本在后台校验，读取期间保持内容版本一致。精简异常提示并提供重试入口，修复 Windows 下载状态文件的并发读写问题。

- 笔记图片右键改为一个竖排菜单（复制图片、评论等），不再并排叠出两个横条。

- 笔记中的图片可复制到系统剪贴板：右键 **复制图片**，或选中图片后按 `Ctrl/⌘+C`（单独打开图片文件时同样可用）；桌面端走 PNG 剪贴板，可粘贴到其他软件或笔记。

- 修复目录分组加速后，附件管理「全部」列表因未建 enrichment 表而返回 Internal Server Error／无法解析 JSON。

- 加快默认远程附件时的笔记粘贴与打开：上传暂存不再在整段复制／哈希期间占用附件锁，同卷优先硬链接（否则单遍哈希+复制）；笔记尺寸的粘贴图片上服务器后保留为本机 vault 缓存，避免正文插图再从 NAS 拉回。较大与非图片暂存仍删除本机原件、只留缩略图。

- 附件服务器自动目录检查放宽：上传目录及相关发现由约 30 分钟改为约 **2 小时**（稳定归档仍可延至最长一周；**立即同步**／**完整核对**仍立刻执行）。

- 加快重启后 **Unity Asset** 等目录规则分组的列表：成员从本机清单用 SQL 过滤，网格不再整库加载资料库（封面／标签仍在详情里补齐）。

- 附件服务器支持 NAS 上的应用写入 **成员目录库**（`LeafLoomCatalog/.../attachments/v1/members/`）：可一次性导入现有服务器文件，之后不再靠全树扫描发现成员。粘贴／上传／迁移上服务器后，**笔记尺寸图片保留为本机缓存**便于正文插图，较大／非图片暂存仍删除、列表只显示缩略图／预览。目录库导入仍不下载原件；其他整文件需 **缓存到本地** 或打开。慢网与断线会退避续跑直到完成（仅认证失败暂停）。同步状态显示成员模式，并提供 **导入现有文件到目录库**。

- 优化 NAS 附件浏览：扫描过程中不再每批刷新整页列表；**本地** 来源不占用远程扫描锁；presence 短缓存；缩略图优先按字节范围拉取；新增 **缓存到本地** 与连接往返时延提示（优先 Tailscale 直连／局域网 WebDAV；列表不依赖极空间 Sync）。

- HTML 项目与设计工作台资源只留在项目目录，不参与附件服务器迁移。若已注册项目仍在 `_attachments` 下，可用一次性脚本 `scripts/localize_html_attachments.py`（默认预览，`--apply` 才写入）迁到 `Web/<名称>/` 并把中央依赖迁到各项目的 `assets/`。附件服务器仍可选：未配置时在 **附件管理** 初始化本机目录缓存即可浏览并上传到本机 `_attachments`。

- 在 **设置 → 附件服务器** 恢复服务器迁移：可按路径分批预览执行，中断后继续同一任务；上传校验后权威原件在服务器，本地 `_attachments` 同路径保留为版本匹配缓存（清理缓存只删本机副本，不删 NAS）。在家优先局域网地址；外出慢链路用 Tailscale `100.x`、小批次与 resume，避免一次整库硬跑。传输中任务卡显示已完成数／总数、字节进度、传输速度、阶段（校验／探测／上传／读回）与当前文件；慢链路 PUT／读回超时已放宽，减少探测阶段一直显示 0 B/s 的误判。服务器读回校验会单独显示下载进度／速度（需再拉整文件做哈希）。

- LeafLoom 技能：「全天／半天」记录时写入 `daily_hours`；汇总工时时若当天有事项仅缺数字，不得报成「没数据」。

- LeafLoom 技能：记录工作时双写事项库与 `工作目录/` 下给人看的周期工作记录（路径见 `work_hub.human_work_log`）。

- LeafLoom 技能：周报默认面向管理者，写结果、风险与支持需求；禁止日期流水账和正文插截图。新增默认周报模板资源，并优先使用中枢已有模板。

- LeafLoom 技能：记录工作且未提供工时时先询问实际小时数；周报只写 Markdown，不再生成 Word 副本。

- 安装 LeafLoom 技能时，会旁路备份并移除已被替代的 `wiki-search` 与 `work-hub` 技能目录。

- 修复顶部路径栏复制失败：在浏览器剪贴板 API 不可用时改用共用剪贴板助手，并在写入完成后再关闭菜单。

- 新增日历备忘录：月历、每日详情和议程列表，共用每日笔记，关联数据库任务并同步单次完成状态，支持重复安排、删除恢复、按知识库隔离的提醒和桌面托盘通知。
- 日历内容通过 `Calendar/LeafLoom` 独立变更文件跨设备同步，支持独立修改合并、同一事项冲突选择、删除记录保留和旧数据校验备份迁移。提醒偏好及投递历史按设备保存，Resilio 可继续排除 `.vault-rag`。

- 将知识库检索、任务管理、工作记录和设计工作台指引统一到 `leafloom` 技能。脚本直接连接本机应用，沿用本机 AI 权限及版本校验。

- 设计工作台预览、对比与演示支持文字和 SVG 图标上的标准公共网页超链接；实际点击通过宿主打开浏览器，保留预览隔离、编辑选择和导出 HTML 的原有行为。

- 修复妙搭首轮发布转入上传或结束后，界面仍等待并误报没有待检查发布的问题；临时状态读取失败可继续重试，上传中断后完整核对确认文件不存在时支持继续上传。
- 妙搭课件使用正式正文入口，等待课件就绪并提供加载失败恢复；补充保留云端改动、同步过期编辑器预览的说明。

- 设计工作台支持自动接入合法的外部源码修改，作为一条可撤销历史且不重写原文件；保留旧版本保存保护，纯格式变化不新增历史，读取失败时明确显示失败与重试，不再一直显示加载中。

## 0.1.8 — 2026-11-05

- 修复 Electron 44 桌面端复制图片失败，改用异步 PNG ClipboardItem 接口，并通过真实 preload／IPC／系统剪贴板回读验证透明图片。

- 设计工作台新增图片来源卡片与原图复制，单图复制快捷键保留源尺寸和透明背景，支持绑定、变体及 PNG 跨软件／笔记粘贴，不修改项目。

- Markdown 笔记左侧新增无边框本页目录，支持原位收起／展开、点击标题或箭头折叠各级子目录、随阅读位置蓝色高亮、正文／源码靠上跳转和编辑同步；窄窗口使用目录浮层。

- 设计工作台页面列表支持带页数的可折叠文件夹，可批量归组、移动页面、重命名或合并文件夹、移回未分组，沿用原有页面分组和撤销历史。

- 设计工作台的左侧图层栏和右侧属性栏支持独立收起与恢复，适用于编辑和对比模式，并保留面板状态。

- 设计工作台新增 **对比** 模式：左侧编辑、右侧独立运行交互预览，保存修改后自动刷新。

- 减少附件服务器重复扫描：按目录活跃度将检查间隔从 30 分钟逐步延长到最长一周，上传目录保持及时检查，上传只标记相关目录复查。空闲资料／分组拉取最长延至 6 小时，失败重试最长延至 1 小时，重启保留计划；修复缓存目录被外部删除后反复重试的问题。手动完整核对仍立即执行。

- 设计工作台支持 Cmd+C／Ctrl+C 复制单选或多选控件的精简定位信息，同时兼容系统菜单“复制”；保留文字、输入框、源码编辑和预览模式的原有复制行为。

- 控件定位信息支持多选复制，共用文件／页面信息并使用精简的 `node_ids` 数组；画布与图层右键已选控件时保留多选，属性面板也可直接复制全部选中控件。

- 精简控件定位信息，仅保留源文件绝对路径、页面／主组件 ID 和控件 ID；仅在适用时附加变体或待保存状态。

- 修复桌面端因网页剪贴板权限被拒而无法复制控件定位信息的问题：改用受信任主窗口的系统复制通道，复制完成后再关闭菜单，并为旧桌面会话和受限浏览器提供选区复制回退。

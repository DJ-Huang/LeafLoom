## 未发布

- 新增可复现构建的 DUFS 符号链接隔离补丁、临时多账号验证脚本及三语单容器配置／迁移指南；保留原密码、附件身份及原件只读保护。

- 字段右键菜单新增“编辑字段”，与顶部入口共用简洁编辑面板；单选／多选支持新增、改显示名称、调色和确认删除，保留原值及未知配置。任务初始／完成状态可在面板内指定接替并一次保存；多选历史值可保留或清除，禁止给新记录赋予已移除选项。

- 详情页属性支持点击、右键与“⋯”菜单：行内重命名、确认删除字段配置、上移／下移；拖动手柄分别保存主要属性与折叠属性的顺序，失败恢复，支持键盘及窄屏菜单。重命名和删除在数据库内共享，原笔记属性值和正文保持不变。

- 记录详情按布局展示必要属性，其余属性默认收起；底部新增参考 Notion 的“＋ 添加字段”，使用简洁的名称／类型表单，一次保存字段与详情显示配置，网页与 MCP 共用，保留笔记正文和原属性值。

- 数据库顶部视图标签支持拖动排序、菜单左右移动和 Alt＋左右方向键；顺序保存后在全屏与嵌入中同步，保留当前视图，失败时恢复，并通过 MCP 提供同样的版本保护操作。

- 数据库新增记录自动采用当前视图中明确且可写的等值筛选，例如任务、设计文案和设定类型；五种视图、看板列内、正文嵌入与 MCP 行为一致，保留显式填写值及超时重试回执。

- 补全数据库 MCP：公开各写命令的结构化参数与能力清单，新增数据库内正文分页读取、保存回执核对和看板分组增改；支持带预览与版本保护的 `.base` 移动、回收与历史恢复，保留记录目录、正文访问边界及读写权限。

- 减少启动后的重复同步：保留检查时间，目录与资料约每 30 分钟检查，支持服务器扫描范围及持久暂停／恢复，复用未变化的缓存断点和资料汇总，并明确显示同步阶段与进度。

- 新增可配置的附件后缀白名单，本地与全部服务器统一生效，默认排除源码；已有列表和统计即时过滤，附件上传同步校验，保留原件与已有链接。

- 数据库看板列菜单新增“删除分组”：预览全部受影响记录，迁移至未分类或现有分组，清理共享选项并显式指定任务状态接替；保留笔记正文，支持草稿／版本保护、失败恢复和窄屏确认。

- 新增记录收到保存回执后直接显示，不再等待目录更新与分页查询；当前分页之外的记录以“刚创建”暂时置顶并自动定位，后台核对后去重，保留筛选、失败与重试保护。

- 优化删除、移动后的响应：按内容版本复用数据库配置与查询快照，只合并刷新相关视图，收到回执即更新记录，删除预览不再刷新。目录变更等待增量队列而非重扫全库，按服务端提示短暂重试；文件移动修复引用时复用路径索引，保留版本保护、历史与可恢复回收。

- 数据库五种视图与嵌入统一增加参考 Notion 的记录右键菜单，支持侧边预览、完整页面、重命名、完整笔记副本、复制笔记链接和确认回收；保留看板移动与排序操作，并支持键盘及窄屏“⋯”入口。

- 修复数据库看板拖动一次后无法继续拖动的问题，覆盖后台异步更新、空目标列与延迟保存回执；增量更新保留完整目录的就绪状态，忽略重复文件通知，并将目录准备中的响应标为可重试。

- 设计工作台页面列表支持右键复制或删除目标页面，删除可撤销并保留至少一页。

- 数据库新增看板与任务预设：分列分页、卡片虚拟滚动、跨列拖动、手动排序、任务状态映射、选项名称与颜色及逾期日期；保留 Markdown 和旧任务视图，支持带版本保护的可恢复移动与撤销、稳定嵌入、键盘菜单及窄屏布局。

- 设计工作台新增“发布到”菜单，妙搭选项显示飞书图标；可选择页面发布到新建或已关联的课件应用，显示依赖提示与素材进度，并保护远端版本。

- 继续统一附件管理、关系图谱与设计工作台，包括项目菜单、附件操作、导出、发布及源码弹窗；修复窄屏附件按钮溢出，优化预览，并新增画布／图层／属性切换，保留工作台状态。

- 统一全应用的字体、颜色、间距、焦点与弹窗层级；更新侧栏分组、首页快捷操作和最近笔记卡片、编辑工具、搜索、设置、AI 与初次使用界面；修复任务勾选框换行，并移除新手样式对全局按钮颜色的强制覆盖。


- 设计工作台 HTML 导出支持选择页面，只打包相关依赖，并提示未选关联页面和脚本动态引用。

- 重做数据库界面：文档式标题、紧凑图标工具栏、轻量单元格、柔和分类标签、拖动列边界及属性浮层；统一画廊、时间线、记录侧栏与窄屏样式。


- 新增笔记数据库：表格、列表、画廊、时间线、类型化字段、版本保护、媒体封面、可编辑的稳定视图嵌入及按权限控制的 MCP 工具。


- 修复切换附件分组时看起来没有变化的问题：标题和加载状态立即切换，主动筛选清除旧列表，失败后明确提示重试；后台索引进度不再反复取消分组读取。

- 修复附件连接恢复后旧同步错误仍常驻的问题：显示实时重连与资料同步状态，临时网络原因默认折叠并提示自动重试，保留最近成功时间，连接恢复立即唤醒资料同步；认证等需处理的错误继续显示。

- 附件目录扫描按目录保存本机断点，断线或重启后继续；增量检查复用有效缓存，每台服务器最多并发读取两个目录。到期子目录独立核对，未变化记录不重复写入；同步弹窗显示复用数量并提供不下载原件的完整核对。

- 附件工具栏直接显示实时扫描进度；同步失败改为可读原因，区分连接超时、响应超时与读取中断，并保留失败时间，不展示敏感网络异常原文。

- 修复大附件目录在后台扫描期间一直停留在“正在读取附件”：合并更新通知，保留正在进行的读取，超时后显示重试；减少不存在的虚拟远端目录的重复本地检查。

- 简化附件界面：详情栏可折叠，概览和同步状态按需打开，已有封面用于预览；新增通用 SMB2/3 连接，与 WebDAV 一起自动后台扫描。设置只保留服务器卡片，新建与导入移到目录操作，移除迁移与整理入口。

- 缩小设计 MCP 返回：公共 MCP 与内置 AI 默认分页摘要，按页面／元素／资源读取源码，分页可固定版本；修改、撤销与导入默认短回执，保留显式完整读取和网页编辑器行为。检查索引按内容版本复用，公共 MCP 在工作线程中紧凑编码 JSON，并记录耗时与返回字符数。

- 服务器附件目录读取超时时最多自动重试两次；扫描仍失败时继续保留旧记录。

- 新增桌面双屏演示者模式：独立观众窗口、实时操作预览、私人讲稿与步骤／案例导航，支持黑屏、断线恢复与固定播放快照。讲稿沿用版本／撤销机制，观众输出和导出均排除讲稿。

- 设计工作台新增全屏演示：隐藏应用工具栏、画板等比例适配屏幕，提供浮动翻页／选页与 Esc 退出；不支持原生全屏时铺满窗口，保留当前交互和原编辑位置。

- 修复笔记保存与后台目录／附件更新互相等待导致回执超时的问题。文件与历史记录写入后立即确认，元数据更新进入后台队列，后续 MCP 请求和编辑器保存可继续使用；保留版本与权限校验。

- 设计素材 MCP 支持引用知识库内文件或当前凭据的飞书临时文件，在服务端复制，减少大文件 Base64 请求与反复传输。可选择简短回执，避免重复返回完整项目；保留旧参数与默认返回、来源和内容校验、权限边界及撤销历史。

- 修复切换新上传位置时隐藏已有本地／服务器附件的问题，分别报告本机目录状态与服务器目录可用性；同名文件不误解析，保留同步删除尚未到达的本地原件，并在三语界面与指南中明确离线、队列与多电脑同步边界。

- 选择服务器后直接使用服务器附件目录，拆开本地目录初始化与可选整理。附件 SQLite、设置、缓存及队列移入本机应用数据，旧状态以一致性快照升级并保留。上传完成或释放原件前先发布并校验服务器引用；其他电脑无需同步 SQLite 即可恢复旧路径和 ID，冲突明确报错，并提供旧引用同步入口。

- 附件服务器支持 Tailscale 等私人 VPN 使用的 `100.64.0.0/10` 数字共享地址，沿用现有私网 HTTP 配置流程；保留来源显式授权，公网 HTTP 地址仍被拒绝。

- 修复旧附件服务器配置缺少元数据目录字段时无法保存的问题；更改地址时保留默认推导的目录和已有凭据，避免服务器错误。

- 新增按附件分组勾选的 AI 素材检索范围，选择随分组资料同步至 NAS。未选择分组时返回空结果；冲突分组暂不收录，商品详情只展示范围内包版本／副本。

- 新增 AI 素材统一检索、可选本地语义排序、真实图片预览与固定目录原文件交付。任务按连接权限隔离，完成后返回经校验的服务所在机器路径；保留旧下载流程，工程接入由调用方 AI 负责。

- 修复 Unity Asset 兼容性信息为对象时，点击附件导致整个附件页面崩溃的问题。详情支持字符串、数组、对象及嵌套数据，空兼容信息不显示。
- 附件管理改为通用文件浏览，支持自建分组 Tab、手动与条件收录、知识库保存及 NAS 读回校验同步，并明确处理并发冲突。保留已有来源简介、标签与官方封面，移除固定商品入口；左侧新增独立下载页，保留原有附件／ZIP 任务，下载容量设置移至下载页。MCP 新增分组查询和带版本核对的编辑。

- 支持缺少 JSON-LD 但保留完整官方商品与发布者数据的页面采集，仍拒绝身份不完整或 ID 不一致的条目。
- 商品资料同步复用 HTTP 客户端与已验证目录检查，减少重复请求；官方转接为兼容可使用独立连接；仍逐件读回校验，失败保留待同步。小型商品资料最多四个受限并行同步，依赖与权限校验继续保留。大目录启动／后台核对按批复用本地已验证事件快照，减少重复本地读写，保留身份、权限及未验证事件 SHA 校验。

- 新增本机批量脚本，支持启动／继续官方商品采集、监控持久进度，以及带版本核对的中文资料局部更新，保留个人字段；官方采集成功与中文整理完成分别统计。中断续跑保留已完成的待核对判断，受阻／网络失败继续重试；后台在已核验检查点下先恢复待传再查远端，首次／主动同步仍先读远端。
- 正常退出中断后台核对时保留上次目录同步结果，避免下次启动误显示服务错误。
- 商品目录的事务内权限校验复用当前连接，修复大量商品资料写入时的数据库锁冲突，保留提交前校验。

- 官方商品采集可沿用 macOS 已有的受支持本机 HTTP 代理，保留官方来源、TLS 和响应限制，不更改系统设置；重复刷新保留中文并在来源事实变化时标记待更新，商品本地查询不再长时间等待 NAS 同步网络。

- 新增已有 Unity 资源包的商品视图，分离官方／个人资料，支持官方链接关联核对与明确的采集进度；保留多份包版本、NAS 商品目录和独立 20 GiB 校验下载暂存，不自动导入 Unity 或验证购买权属。

- 已保存附件凭据改为后台恢复，优先使用异步系统加密接口，避免密钥库等待阻塞知识库启动；合并恢复重试，丢弃旧后台连接的迟到结果。

- 服务器各目录支持可见 `leafloom.ignore`，要求首行 `# leafloom-ignore v1`，按 Gitignore 风格模式、子目录覆盖及 `!` 重新纳入。刷新成功后显示排除数量并从附件发现与统计隐藏，保留 ID、标签、旧引用及缓存；规则只读取得，无需 NAS 写权限。

- 附件管理新增明确的单服务器目录刷新，显示元数据同步进度与完成状态。仅完整扫描成功后隐藏 NAS 缺失文件并更新容量；保留资产 ID、标签及旧引用，失败保留原记录。

- 附件顶部容量按本地与服务器分别显示原件大小，筛选单一来源时仅显示该范围，统计不含本地缓存。

- 附件密码恢复新增 1／3／10／30 秒有限重试、解锁／唤醒重试和设置状态／手动恢复入口；NAS 网络与 502–504 按 2–60 秒退避，401／403 暂停同密码自动尝试。健康探测仅访问已配置地址，旧任务仍校验所有者与凭据版本；官方窗口仍需保持开启，不能自动重建。

- 附件管理新增来源下拉，可分别浏览全部、本地、服务器或指定服务器。网页与 MCP 共用服务端来源筛选、分页及数量、容量和类型统计。

- 新增通用多服务器 WebDAV 附件配置、桌面系统加密凭据、浏览器会话内凭据、有界本地缓存及独立待上传队列。支持先预览再执行本地到服务器迁移，读回校验后释放原件并保留 LeafLoom 内旧引用；可编辑标签、分类、简介并查看原件及缓存状态。官方客户端桥接需保持附件窗口开启并维护转发端口。

- 新增不超过 2 MiB 的 Base64 普通附件一次上传与 SHA-256 校验；图片上传返回 Markdown 嵌入引用，能力状态明确上传方式及客户端工具目录刷新提示。保留现有两个文件工具、分块传输和 ChatGPT 文件输入。

## 0.1.5 — 2026-10-29

- 附件服务器支持多台通用 WebDAV／SMB2/3，仅突出地址、账号、密码；切换新附件保存位置保留已有根目录、ID、引用与资料库绑定。
- 连接恢复后自动发现目录，按目录保存跨断线／重启的断点，复用十分钟缓存并独立核对到期子目录，每台最多两个目录读取线程；缺失判定仍需完整扫描与不存在确认。
- 附件浏览提供手动／规则分组、紧凑工具栏、可折叠详情、按需概览和已有封面预览；修复初次读取转圈、切组残留旧列表和恢复后旧错误常驻，后台更新保留浏览与草稿。
- 下载独立成页，支持原件校验准备与可配置暂存；新建／导入移到目录操作，隐藏迁移／整理入口，保留任务记录、恢复材料及常规文件操作。
- 新增按已选分组授权的 AI 素材资料检索、真实预览、可选本地语义排序和固定本机目录交付，与笔记检索范围分离。
- 已有 Unity 资源包可关联经过核对的官方商品、多版本、个人整理与真实封面；批量采集可续跑，保留中文资料和个人字段，小资料并发同步，不自动导入 Unity 或验证购买权属。
- 分组、引用与资料使用不可变服务器记录、读取验证和明确冲突；活动 SQLite、待上传队列及缓存保存在设备私有目录，保留旧状态恢复快照。
- 桌面凭据异步恢复，NAS 临时故障自动退避、认证失败暂停；支持数字形式的私有 VPN HTTP 地址，公网继续要求 HTTPS。
- HTTP／MCP 附件工具共享来源筛选和版本校验，支持分组／资料操作及不超过 2 MiB 的 SHA-256 校验 Base64 一次上传，保留既有工具名、分块传输、旧 ID 与引用。
- Design Studio 新增全屏预览、独立观众输出、实时控制台、私人讲稿、步骤导航及断线保护的桌面演示者模式。
- 设计 MCP 支持定向／分页读取、简短修改回执和服务端素材导入；笔记保存提交后异步更新资料，修复保存响应相互等待。
- 修复三语帮助文档结构，补充本版发布与升级说明。

## 0.1.4 — 2026-10-19

- 修复 Design Studio 在跨电脑同步、知识库根路径不同时误报项目属于其他目录的问题，支持 Windows 与 Mac 之间同步。读取时保留项目 ID 与历史归属，继续拦截不同目录的重复 ID 和内容冲突，并兼容同步后的项目移动、恢复与回收站清理。


- 浮动工具栏与选区右键菜单新增 **清除高亮**，可将选中文字恢复默认；保留选区外颜色与评论，多条高亮一次清除、整体撤销／重做。

- 高亮、评论、回复、编辑、解决／重新打开、重新关联及删除支持撤销／重做，与正文和源码按顺序共享历史；新增顶部按钮，恢复时检测并保护并发评论修改。

- 新增 Markdown 五色行内高亮、行内及页面评论、回复编辑、解决与重新打开、右侧评论面板和源码模式标注展示；通过独立 SQLite 保存评论，不污染 Markdown，并在 LeafLoom 的移动、删除恢复与 MCP 操作中保持关联，提供需授权的 MCP 评论工具。
- 新增三语公开帮助中心，每种语言包含 39 篇任务指南与 4 篇完整指南／版本参考，支持全文搜索、分类导航、页内目录、前后篇、图片放大与示例复制。官网与应用侧栏直达当前语言帮助，文档改动纳入 Pages 构建发布。

- 在应用与托盘菜单加入 **重启 LeafLoom**，沿用草稿检查并等待本地服务正常停止。Dev 保留 Vite、同步锁定的 Python 依赖后重新加载源码；未保存提示中选择返回会取消重启。

- 将附件弹窗升级为独立网格／列表工作区，支持全库名称／路径搜索、筛选排序与就地媒体预览。新增一键准备、明确的后台进度、同名保留上传、带引用检查与恢复的重命名／移动／回收、异步 ZIP 下载，工程资源保持只读并适配窄屏。

- 附件迁移保留 HTML／源码项目与共享资源，沿字面量目录和配置引用扩大保留范围；二进制工程文件不再误作文本阻止迁移，独立附件继续迁移并保留漂移校验与回滚。

- 区分附件迁移预览被阻止与索引初始化，补充常见阻止原因的翻译，并为阻止项与排除项显示已展示数和总数。

- 修复 macOS 开发模式的 Dock 图标与名称：通过 Dev 启动时使用缓存的品牌运行器，显示 LeafLoom logo 与名称。

- 将附件索引初始化／升级与目录迁移合并为一个流程：自动准备索引、预览，然后一次确认完成复制、引用改写、原文件可恢复归档和最终索引重建。仅维护索引放在默认折叠的高级选项中。打开管理器保持只读，HTML 项目不参与迁移。

- 新增需明确确认的异步附件迁移预览，支持持久化进度、安全阻止项、停止、日志恢复和确认回滚。保留原附件与笔记备份，迁移完成后新上传使用统一目录。

- 新增仅保存元数据的 SQLite 附件索引及侧栏附件管理，支持按名称／路径分页搜索、原文件下载、刷新、取消与重试。原文件、HTML 项目和现有 URL 保持不变。

- 修复正式 Release 发布时官网重复部署的问题；若 GitHub 最新 Release 接口尚未更新，则先重试，避免将旧版下载链接重新部署到 Pages。

## 0.1.3 — 2026-10-18

- 优化设计工作台层级与页面操作分组；批量发布采用固定操作栏、输出摘要和可展开结果。新增 ATELIER 灯具品牌模板，提供三个可编辑画板与完整中英日变体。

- 新增文字与图片稳定数据绑定、可复核的语言及通用变体、变体布局覆盖、文字与素材预检及有界适配，并支持按页面和变体批量导出 PNG ZIP 或多页 PDF，显示进度并可重试；保留交互 HTML 导出与撤销、冲突保护。

- 新增明确的编辑 / 预览切换：直接进入无遮挡的交互画布，支持切换页面与重播；先完成最新修改保存再预览，失败保留修改，返回时恢复原编辑页面、选中图层与画布位置。

- 新增可试玩的 Motion Playground 内置模板，展示可编辑的原生动画和 JavaScript 交互，附触屏布局与项目内说明。支持实时减弱动态效果设置、聚焦/触屏反馈，避免反复交互积累动画。

- 打磨设计工作台日常编辑：增加框选、吸附参考线、方向键微调、基于实际画布坐标的对齐与等距分布、多选缩放及自动布局拖动排序。补齐可视尺寸、排版、效果、图片裁切、关联样式与组件覆盖/重置，明确导入保真范围和待保存恢复反馈；新增内容自适应卡片、FORMA 换品牌及 HTML 编辑后 ZIP 重开验收。

- 修复选择目录意外提交设计项目创建的问题。空白与 FORMA 项目均需显式点击创建，清晰显示父目录和目标路径，校验文件夹名称并防止重复点击。

- 新建设计项目可选择内置 FORMA 编辑式工作室模板并查看预览，包含四个可编辑画板和 328 个图层。每次创建具有独立文档历史、随包素材和目录防覆盖保护。

- 改进设计工作台导航：保留平移与缩放状态，提供选择/抓手工具、适应页面/选区、可折叠图层、选中路径及分组属性面板。画布连接失败时提供重试。转换时保留更多 HTML 文档上下文、混合文本和响应式资源，同时保留原始源码及独立预览边界。

- 设计项目回收站新增永久删除和清空，支持确认、版本校验及中断后继续清理；同步移除相关项目恢复记录，保留其他项目历史和共享库。

- 修复新版项目首页连接旧后台时仅显示 Not Found、删除点击无反应的问题：明确提示重启应用，管理状态就绪前禁用相关操作，并提供重试。
- 官网三语首页加入现有英文演示视频，提供原生播放控件、本地化截图封面和视频直达链接。

- 新增可选浏览器开发启动器，使用显式隔离的状态目录与 Vite 前端。按需启用 `--loopback-ui`，让管理界面使用 `localhost` 兼容受管浏览器，保留鉴权与 HTML 项目独立来源；项目预览仍可能受影响。常规桌面启动与安装器支持平台保持不变。

- 推送匹配版本标签后，由 GitHub 自动构建 Windows x64 与 Mac arm64 安装包，生成含已验证 SHA-256 校验文件的 Release 草稿，由维护者手动发布。保留手动构建附件入口，禁止覆盖已公开版本；无证书 Mac 构建使用临时签名且不公证。

- 将设置侧栏入口与页面标题“AI 集成”统一改为“Skill”。

- 官网新增中英日三语 About 页面，提供作者 GitHub 和 X 个人主页链接，并在导航与页脚加入入口。

- 官网按 Windows / Mac 分别保留最新可用正式版安装包，并对应显示版本、说明与校验文件；Pages 环境允许 `v*` 标签，使 Release 事件可自动部署。

- 设计工作台扩展为可视化 HTML 游戏画面工作台：新增项目首页与回收站、素材信息与替换、可复用组件与嵌入子页面、版本化个人共享库及独立 ZIP 导出。旧版 1.1.0 项目继续打开，转换副本保留原生 DOM/CSS，并适配可识别的导航、开关与上下文页面状态；原脚本保留在复制源码中，其他运行时行为需补写新脚本。

- 页面、源码、素材和直接应用的 AI 批量修改共用持久事务撤销/重做，关闭重开后仍可恢复。新增版本校验、幂等重试、待保存恢复与外部修改保护；提供动画预设、元素/页面 `mount(ctx)` 脚本、可调参数、隔离试播、资源清理及日志定位。拖动每帧仅更新选中节点，结束提交一次事务；真实项目与压力样例的性能预算保留为明确验收目标。

- 合并后的 HTTP MCP 共提供 42 个工具：23 个笔记工具、14 个设计工作台工具及 5 个可选飞书工具；笔记与飞书继续独立授权。升级后刷新客户端工具清单；受管设计使用文档、批量操作、历史、素材、共享库与导出接口。

## 0.1.2 — 2026-10-16

- 修复不同 ChatGPT 聊天通过同一 Tunnel 获得不同 MCP 权限：运行时使用独立鉴权请求头，避免聊天连接的 Authorization 覆盖内部凭据；资源授权与即时撤销保持生效。

- 设置 → 常规新增应用更新：显示当前与最新版本，提供安装包校验、下载进度条，并在正常退出后打开安装程序；macOS 打开 DMG，源码 Dev 仅检查版本。

- Dev 与安装版统一共用用户数据目录、配置、模型、AI/MCP 凭据、桌面 profile 和服务端口；开发依赖保持独立，目标模型目录缺失时安全复用旧 Dev 模型。

- 模型设置与首次引导显示实际模型保存路径，并支持打开目录；首次下载前也可查看空目录。

- 检索设置与首次引导持续显示模型准备阶段、下载量与速度、已用时间、等待提示及失败重试详情；避免重复准备、下载十分钟提前超时和权重重复校验。

- 加强私有配置、凭据与本地状态的忽略规则；清理仓库历史中的个人路径与私有提交邮箱，保留公开作者名称。

- 移除旧仓库启动入口；安装版自行管理，源码开发统一使用 Dev。

- 新增 Windows `Dev.cmd` 与 Mac `Dev.command` / `Dev.sh` 一键源码桌面开发入口，支持前端自动更新，使用独立 Python 环境，并共用安装版用户配置。

- HTTP MCP 扩展至 23 个工具，支持全目录查找、Markdown/TXT/HTML 编辑、属性、目录、引用修复移动、回收区、历史恢复、模板、日记与索引同步。
- 本机与 ChatGPT 使用独立 MCP 凭据和写入开关，默认只读；保留旧检索范围与内置助手提案流程。
- 校验知识库、文件及操作版本，保留 BOM 与换行，移动失败回滚时保护外部修改。

# 更新记录

[English](../../CHANGELOG.md) · [中文](CHANGELOG.md) · [日本語](../ja/CHANGELOG.md)

## 未发布 — 2026-10-16

- 内置「设计工作台」，支持在当前关联知识库的任意目录内直接新建 1.1.0 设计项目、新增页面画板，并在画布上使用类 Figma 图层操控（智能对齐参考线、八向缩放、旋转、属性面板、撤销/重做、`Design/layer-transforms.json` 持久化、原素材与实时 PNG/SVG 双模导出及发送图层给 AI）。
- 加强私有配置、凭据与本地状态的忽略规则；清理仓库历史中的个人路径与私有提交邮箱，保留公开作者名称。
- HTTP MCP 扩展至 29 个工具（新增 6 个 `design_*` 设计项目、页面、图层与验收工具），并支持全目录查找、Markdown/TXT/HTML 编辑、属性、目录、引用修复移动、回收区、历史恢复、模板、日记与索引同步。
- 本机与 ChatGPT 使用独立 MCP 凭据和写入开关，默认只读；保留旧检索范围与内置助手提案流程。
- 校验知识库、文件及操作版本，保留 BOM 与换行，移动失败回滚时保护外部修改。

## 0.1.1 — 2026-10-15

- 内置 Secure MCP Tunnel 设置、加密凭据保存及连接生命周期管理。
- 改善笔记编辑体验，补充多语言入门示例。
- 发布 macOS Apple Silicon 安装包；沿用 0.1.0，不签名、不公证。
- HTML 按项目运行，支持指定资源根目录、SPA 路由、独立持久来源、网页导航与下载，也可打开已有 HTTP/HTTPS 网站或开发服务。
- 从旧回环地址迁移浏览器草稿和视图状态，冲突时保留恢复备份；增加 macOS 14/15 Safari 专属兼容配置。
- Markdown 正文直接编辑，支持斜杠命令、块拖动、表格、链接、公式、图表及粘贴或拖入附件。
- 正文与源码共用撤销历史，保留未修改原文及属性，保存冲突时保留草稿。

## 0.1.0

- 中英日三语界面、共享桌面文案和独立语言偏好。

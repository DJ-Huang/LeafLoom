# 数据绑定、语言变体与批量发布

## 使用目标

复用文案与图片，输出选定页面和变体的 PNG 或 PDF。

## 开始前

先打开一个设计项目，并等待已保存状态。

## 操作步骤

在设计工作台右侧打开“数据”，把文字、按钮或图片绑定到稳定数据键，创建语言或其他用途的变体并填写内容。图片复用已有素材 ID。源数据更新后，旧翻译会提示复核；变体布局覆盖可调整文本框和页面尺寸，不会替换源布局。修改沿用正常保存、撤销和冲突恢复。

打开“批量发布”，选择页面和变体，核对尺寸并检查所选输出，可生成 PNG 压缩包或一份多页 PDF。“检查当前画布”能定位溢出和字体、素材风险。优先修改内容或文本框；明确点击文字适配后才会按最小字号和最大缩小比例调整。缺字与回退字体检测并非完整字体审查。失败项可按同一已保存快照重试。桌面版使用内置渲染器；网页或无界面服务器需要可选发布依赖。原有交互预览和 HTML ZIP 导出继续可用。详见[发布说明](../../DESIGN_STUDIO.md#bound-content-variants-and-static-publishing)。

数据绑定和变体属于各自项目。发布到共享库的组件会固定源内容并去掉原项目的绑定链接；导入后可重新绑定到目标项目的数据键。

### 编辑式品牌模板与清晰的发布工作区

新建项目时选择 **ATELIER**，可获得三个灯具营销画板、可编辑文字、原创雕塑感图形，以及完整的中英日变体。在“数据”中编辑绑定源文案或切换变体；空白、FORMA 和 Motion 模板继续适用于其他通用设计工作。

工作台将编辑工具与导出、发布分组。页面排序、复制、删除收纳在页面属性的“页面操作”中。批量发布的操作栏始终可见，选择页面、变体、格式后核对摘要，再检查所选输出并发布。已完成项目以可展开的紧凑行显示，失败项展开诊断；文字适配限制与检查说明可按需展开。静态检查不能代替字体与版式的目视复核。 窄窗口下可使用画布工具栏的“隐藏面板”扩大画布；“显示面板”会恢复原来的属性与图层选择。

## 完成后的表现

得到静态 PNG 压缩包或多页 PDF，交互项目仍可导出 HTML ZIP。

## 没有成功时

检查溢出、字体与素材；静态检查后仍需目视复核。失败项可使用同一快照重试。

# 记录并找到第一篇笔记

## 使用目标

完成新建、编辑、连接和重新打开的一次完整流程。

## 开始前

已[关联知识库](first-vault.md)，建议使用演示目录。

## 操作步骤

1. 点击 **新建笔记**，选择已有父目录并填写未使用的文件名。
2. 写一段文字，输入 `/h2` 插入标题，输入 `/todo` 记录待办。
3. 输入 `[[` 并按完整路径选择另一篇笔记，建立连接。
4. 等待普通编辑自动保存，切换到其他笔记再回来检查。
5. 按 `Ctrl/⌘+K` 输入文件名，重新打开刚才的笔记。

## 完成后的表现

磁盘目录里出现普通 Markdown 文件，可由其他编辑器读取。

## 没有成功时

若处于 AI 手动草稿，请用 **保存草稿** 或 `Ctrl/⌘+S`；冲突时保留草稿。

# 连接本机 MCP 客户端与 Skill

## 使用目标

让其他 AI 客户端在显式权限下读取或修改笔记。

## 开始前

先关联一个本机目录；建议用演示知识库练习。

## 操作步骤

现有知识库读写开关同时覆盖附件。更新后重启后端，刷新本机客户端与 LeafLoom ChatGPT 插件的工具列表。`vault_files` 提供查询、详情、原始字节读取、ZIP 下载和任务状态；`vault_files_update` 提供聊天／本机上传、移动／重命名、回收、整理、索引维护及任务控制。先审查方案，再携带当前任务版本确认执行。上传保留同名文件，返回链接而不自动修改笔记。详见[文件工具契约](../../MCP.md#general-file-tools)。

打开 **设置 → AI 连接 → MCP 访问权限**，启用本机 AI 读取并复制生成的连接配置。专用凭据仅显示一次。Codex 使用 `http_headers.Authorization`，Cursor 使用 `headers.Authorization`，Claude Code 使用 `type: http` 和 `headers.Authorization`。重新生成凭据或关闭全部资源权限后旧凭据立即失效，请勿共享配置。

需要直接保存时，另行开启 **允许本机 AI 修改笔记**。ChatGPT 沿用已有 Tunnel，分别开启它的“读取全部笔记”和“修改笔记”开关；权限变更后自动重连，请在客户端刷新工具列表。两种连接默认都关闭写入。

完整访问覆盖关联目录内全部 Markdown、TXT、HTML/HTM，包括归档和未勾选 RAG 的笔记。支持查找、分段读取、创建、精确修改、属性、移动、可恢复删除、历史、链接、模板与日记。RAG 仍只使用已选择且符合条件的 Markdown/TXT；HTML 按源码读写。旧的本机免鉴权连接及旧 bearer 凭据继续保留原有五项只读能力，旧 `auth-token` 不能开启完整访问。

所有修改校验知识库版本，已有笔记还需读取时的文件版本。移动、删除先返回影响预览；历史与回收区可先预览再恢复。MCP 读取磁盘版本，界面中冲突的未保存草稿继续保留，并明确区分保存成功与索引待更新。网页助手的笔记编辑仍使用原有提案流程。受管设计使用 `design_document`、`design_operations` 以及设计历史、素材、共享库和导出工具，沿用该连接的读写权限。

**设置 → Skill → 安装技能** 安装 `wiki-search` 指令，不自动配置 MCP。详见[完整工具契约](../../MCP.md)。

CLI 未被发现时，先确认终端可以运行它，再重启服务以获得最新 PATH。登录过期在 CLI 中重新登录。会话恢复失败时保留历史并处理 CLI 状态，不要删除知识笔记来修复对话。

### AI 素材检索与交付

检索前，先在所需附件分组的编辑窗口勾选 **用于 AI 素材检索**。全部分组默认关闭，只收录已选分组的成员并集；未选择时返回 `scope_not_configured`，不回退到全库。开关随分组资料同步到 NAS，有冲突的分组暂不收录，需明确解决。普通附件浏览和笔记引用不受影响。

在 **下载 → 下载设置** 配置素材交付目录，并按需启用已准备本地模型的素材语义索引。AI 使用 `vault_files` 的 `search_assets`、`asset_details`、`asset_preview` 查找已有本地／NAS 素材、核对版本及查看真实预览，再用 `vault_files_update` 的 `deliver_asset` 下载并轮询 `delivery_status`。只有完成后返回服务所在机器的完整路径；交付文件不随缓存清理，由 AI 自行接入工程。没有模型仍可关键词检索；本版不索引包内资源或图片外观相似度。

## 完成后的表现

完整访问与 RAG 范围独立；Skill 安装不会自动配置 MCP。

## 没有成功时

更新或轮换凭据后重新加载客户端，检查状态返回的实际权限。

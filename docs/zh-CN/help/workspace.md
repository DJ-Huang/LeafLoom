# 认识工作区与功能入口

## 使用目标

按任务选择目录、检索、附件、设计或设置入口。

## 开始前

打开一个知识库。界面语言可在常规设置修改。

## 操作步骤

1. 左侧目录浏览本地文件；首页展示最近内容和新手清单。
2. **知识检索** 搜正文依据，**关系图谱** 看连接；`Ctrl/⌘+K` 按名称找文件。
3. **附件管理** 处理媒体与下载，**网页** 打开网址，**设计工作台** 创建可编辑设计。
4. **AI 对话** 使用可选助手，**设置** 管理范围、连接、历史和回收区。
5. **新手指南** 重新显示首页清单，**帮助中心** 打开当前语言的完整文档。

## 完成后的表现

按内容类型进入对应工作区，不需要把所有资料加入知识检索。

## 没有成功时

关闭窗口通常只是隐藏到托盘；停止服务请选择托盘中的 **退出**。

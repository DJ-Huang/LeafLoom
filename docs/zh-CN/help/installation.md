# 安装并打开 LeafLoom

## 使用目标

完成桌面安装并看到欢迎页。

## 开始前

确认[系统要求](requirements.md)，先保存其他应用中的工作。

## 操作步骤

1. 从[官网](../../../README.md)的下载入口选择 Windows 或 Mac 安装包。
2. Windows：运行 `LeafLoom-*-windows-x64-setup.exe`，按向导安装后从开始菜单打开。
3. Mac：打开 `LeafLoom-*-macos-arm64.dmg`，拖入“应用程序”，再启动该应用。
4. 若系统拦截，核对下载来源并阅读[安装问题](installation-problems.md)。
5. 欢迎页选择语言，先体验演示库或关联目录。

## 完成后的表现

欢迎页出现后即可设置资料目录，无需先下载检索模型。

## 没有成功时

当前包没有受信任发行签名；Mac 使用临时签名且未公证。不要关闭全局系统保护来排查。

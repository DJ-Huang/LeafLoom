# 双向链接、反向链接与图谱

## 使用目标

让相关笔记可相互导航，并通过图谱发现连接。

## 开始前

准备至少两篇 Markdown 笔记。图谱不依赖语义模型。

## 操作步骤

1. 在正文输入 `[[`，输入名称并从候选中按完整路径选择目标。
2. 打开链接到的笔记，查看指向它的反向链接。
3. 进入 **关系图谱**，搜索笔记并筛选目录，再沿连线探索。
4. 重名笔记使用完整相对路径；移动或重命名尽量通过 LeafLoom 完成。

![关系图谱](../../../assets/screenshots/zh-CN/05-graph.png)

## 完成后的表现

图谱展示本地 Markdown 链接关系，不是语义相似度或引用可靠性的证明。

## 没有成功时

没有连线时先检查链接目标、拼写与过滤器。外部编辑器改名后需重新核对引用。

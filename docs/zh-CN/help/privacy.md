# 了解本地数据与外部访问

## 使用目标

了解资料何时留在本机、何时会发给外部服务。

## 开始前

区分本地浏览、选定检索范围、AI 引用与完整 MCP 权限。

## 操作步骤

1. 本地阅读、图谱和检索在本机运行；模型首次下载需要网络。
2. 发送 AI 问题前核对选文、当前笔记与检索引用。所选模型服务可能接收这些内容。
3. MCP 工具结果会交给调用客户端。完整读取权限可覆盖未加入 RAG 的笔记。
4. 飞书操作访问云端，返回所请求资源；不会自动同步到本地知识库。
5. 保管凭据与备份，不把本机服务端口当作公网多用户服务暴露。

## 完成后的表现

可以分别控制本机、Tunnel、笔记、飞书及写入权限。官网帮助中心是独立静态内容，不读取知识库。

## 没有成功时

HTML 项目使用独立来源，但仍应审查不可信网页和脚本。权限与隔离机制不替代系统账户保护和备份。[技术边界](../../SECURITY.md)。

# 任务、数据视图与属性查询

## 使用目标

将带属性的笔记展示为任务、表格或日历。

## 开始前

先打开演示库里的示例视图，使用虚构任务练习。

## 操作步骤

1. 为笔记设置一致的 `status`、`priority`、`due` 等属性。
2. 打开 `.base` 文件，在已有视图之间切换。支持的配置可展示表格、任务列表、看板或日历。
3. 修改表格中的可写属性，或在任务视图修改状态；改动保存到原笔记。
4. 对只读的 `file.*`、公式字段不要直接输入。属性查询使用受限 TABLE/LIST 语法，不运行任意代码。

## 完成后的表现

视图是原笔记的展示方式。拖动任务或编辑属性会真实修改原文件。

## 没有成功时

只支持已有安全语法和受支持的视图，并非完整 Dataview 或 TaskNotes 插件环境。视图报错时先检查字段与配置。

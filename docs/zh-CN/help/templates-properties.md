# 模板、日记与笔记属性

## 使用目标

复用笔记结构，以属性组织资料。

## 开始前

在知识库中准备模板目录和日记目录；路径相对知识库根目录。

## 操作步骤

1. 打开 **设置 → 模板与日记**，填写模板目录和日记目录并保存。
2. 从模板新建笔记，或使用今日笔记入口。已有日记不会被同名覆盖。
3. 在笔记属性区查看和修改 YAML 属性；需要时切到源码核对。
4. 用一致的 `status`、`tags`、`due` 等字段组织同类笔记。

```yaml
---
title: Reading notes
tags: [reading]
status: open
---
```

## 完成后的表现

属性仍属于 Markdown 文件；模板用于创建新内容，不会持续同步已有笔记。

## 没有成功时

目录和文件名冲突时换用新名称。属性类型保持一致，未知字段不要随意移除。

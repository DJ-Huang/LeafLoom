# 检查并安装更新

## 使用目标

确认版本并按正常安装流程升级。

## 开始前

先保存资料，阅读[更新记录](../CHANGELOG.md)，重要内容另行备份。

## 操作步骤

1. 打开 **设置 → 常规 → 应用更新 → 检查更新**。
2. 有新版时选择 **下载并安装**，查看百分比及已下载大小。
3. SHA-256 校验后正常退出；取消退出可稍后选择 **继续安装**。
4. Windows 完成安装向导；Mac 将 DMG 中新版拖入应用程序，再重新打开。
5. Dev 仅检查版本，更新源码后重新运行 Dev。

## 完成后的表现

升级保留笔记目录、配置、索引和模型，仍建议事先备份。

## 没有成功时

检查或下载失败可重试。仅刷新页面不会升级后台。版本和当前可用安装包可能分别来自不同正式 Release，以下载标注为准。

# 关联第一个知识库

## 使用目标

选择本机资料，明确浏览和检索范围。

## 开始前

先用演示库熟悉操作；关联真实文件前保留备份。

## 操作步骤

1. 欢迎页选择 **体验演示知识库**，或用 **关联自己的目录 → 选择目录** 选一个本机文件夹。
2. 选择 **关联并继续**。原文件不会搬走，之后的编辑保存会直接修改这些文件。
3. 在检索范围中勾选参与知识检索的目录，或选择 **暂时只浏览**。
4. 选择 **开始探索**。之后可在设置中切换目录与检索范围。

![欢迎页](../../../assets/screenshots/zh-CN/01-welcome.png)

## 完成后的表现

目录可立即浏览，检索索引在后台准备。演示库各语言独立，重复打开保留修改。

## 没有成功时

使用本机路径。UNC 网络共享、符号链接和 junction 不支持作为越界访问方式。

# 排查 AI、MCP、Tunnel 与飞书连接

## 使用目标

先确定失败的是哪一层，再修复账号、连接或资源权限。

## 开始前

记录连接类型、版本、脱敏错误及最近是否升级或轮换凭据。

## 操作步骤

1. AI 对话：在终端确认 CLI 可运行且已登录；更新 PATH 后重启服务。
2. 本机 MCP：核对地址、专用凭据和该连接的读取权限，升级后刷新工具。
3. Tunnel：核对 ID、Runtime App Key 和通道状态，同一配置仅保留一个受管实例。
4. 飞书：核对 CLI 安装和授权，再验证具体文档或表格权限。`leafloom_mcp` 是本地授权错误，`feishu_cli` 是上游错误。
5. 写入超时、结果未知或部分成功后先读取实际资源，再决定是否重试。

## 完成后的表现

能把客户端缓存、本地访问授权、通道和飞书资源错误分别处理。

## 没有成功时

不要公开配置或令牌，也不要为排错开放全部写入。账号或通道验证成功不代表资源调用成功。

# 安装受阻、白屏或无法启动

## 使用目标

区分平台不兼容、系统拦截、旧进程与后台加载问题。

## 开始前

记录应用版本、系统版本、安装来源和错误，不公开个人路径。

## 操作步骤

1. 核对 Windows x64 或 macOS 14+ Apple Silicon 要求及安装包类型。
2. 被系统拦截时确认来自项目官方 Release，查看系统给出的具体原因；保留全局安全保护。
3. 从托盘正常退出旧实例再重新打开；关闭窗口未必停止服务。
4. 只刷新网页不会更新 Python/Electron，源码改动需重启 LeafLoom。
5. 在桌面常规设置中打开日志文件夹，脱敏后记录最早的启动错误。

## 完成后的表现

能够识别安装、端口占用、后台版本与界面错误所属阶段。

## 没有成功时

不要删除知识库、模型、凭据或历史来修复白屏。仍失败时提交可复现步骤与脱敏日志。

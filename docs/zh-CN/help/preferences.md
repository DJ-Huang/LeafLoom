# 语言、目录、重启与后台运行

## 使用目标

调整日常设置并正确停止或重新加载应用。

## 开始前

保存正在编辑的内容，注意 AI 手动草稿。

## 操作步骤

1. 在 **设置 → 常规 → 界面语言** 选择中文、English、日本語或系统语言。
2. 设置中可切换关联知识库；各路径和检索范围以当前知识库为准。
3. 在桌面设置或托盘调整登录启动，新安装默认关闭。
4. 用应用菜单或托盘的 **重启 LeafLoom** 重新加载，未保存提示中返回可取消。
5. 关闭窗口保留后台；选择 **退出** 停止本地服务和连接。

## 完成后的表现

切换语言保留文档、草稿和位置，不重建索引。Dev 重启会保留 Vite 并同步依赖。

## 没有成功时

Dev 与安装版共用实际数据和默认端口，切换前先从托盘退出已有实例。开发测试需显式使用独立数据目录。

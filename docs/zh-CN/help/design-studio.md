# 创建设计项目与编辑画布

## 使用目标

制作游戏界面或网页画板，并保留项目历史。

## 开始前

先关联一个本机目录；建议用演示知识库练习。

## 操作步骤

相同 **页面分组** 的页面会合并显示在一个带页数的文件夹中，即使它们在文档中不相邻。点击文件夹行可展开或收起。在“页面”标题旁点击 **文件夹分组**，勾选页面后选择已有文件夹名称或输入新名称；留空则移回未分组。文件夹旁的整理按钮会选中该文件夹的全部页面，改名即可重命名或合并文件夹；页面右键菜单也有 **移动到文件夹**。文件夹至少包含一个页面，移空后不再显示。分组沿用项目保存和撤销历史，不改变演示顺序；切换页面时会自动展开其所在文件夹。

左侧图层面板和右侧属性面板的顶部标签栏各有收起按钮。画布工具栏提供独立的 **展开／收起左侧面板** 和 **展开／收起右侧面板** 按钮，编辑与对比模式都可以单独收起任意一侧。展开后保留标签、选择和草稿。工作台较窄时，通过 **图层** 或 **属性** 重新打开面板，点击面板的收起按钮返回画布。

- 项目首页提供搜索、最近打开、收藏、重命名、复制、移动、归档与可恢复回收站。工作区撤销/重做处理项目管理，项目历史处理跨页面、关闭重开后的设计修改。
- 在 **页面** 中新增、分组、排序或复制画面；插入文字、图片、容器、按钮、形状、SVG、自定义 HTML、嵌入子页面，或 HUD、角色卡、图鉴、弹窗等游戏起步组件。点击图层、按住 Shift 多选，通过画布与属性面板调整位置、尺寸、角度、文字、外观及横排/竖排/网格布局。子页面和组件实例保留独立身份。
- 在 **素材** 中上传或粘贴图片，查看尺寸与透明信息，编辑名称、分类和标签，定位使用处，替换单张图片或全部引用。将组件、素材发布到个人共享库后可跨项目导入，更新版本需明确选择。依赖资源会复制到项目中，供离线使用；仍有引用的素材须先替换或移除使用处才能删除。
- **动画** 面板提供淡入、位移、缩放、弹跳、呼吸和旋转；**脚本与源码** 可为元素或页面编写 `mount(ctx)` JavaScript，并把参数暴露为属性控件。编辑时暂停脚本，可试播组件或整页交互，停止后恢复设计状态；日志可定位元素。代码和参数修改进入同一撤销历史。
- **添加到 AI 对话** 会携带元素稳定 ID 与当前版本。受管设计修改直接应用，一次 AI 批量指令对应一次撤销。`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做，关闭重开仍有效。保存冲突保留待处理修改，请查看后再选择重新加载/重新应用。等待保存完成后导出，解压并连同配套文件打开 `index.html`。

- HTML 转换保留文档根上下文、混合文本和响应式图片候选。无法读取的外部样式表会被省略并提示，原始源码不变。视口/rem 单位及媒体查询仍使用渲染器环境。原始文本节点只提供内容编辑，布局和文字样式应选择父级调整。使用前请与原页面对照检查。

- 使用**选择**（`V`）和**抓手**（`H`）浏览画布，也可按住空格拖动。缩放百分比、加减按钮、适应页面（`Shift+1`）及适应选区（`Shift+2`）控制视图；Ctrl/⌘+滚轮围绕指针缩放。编辑时保留画布位置。**图层**中的容器可折叠，底部选中路径可返回父级；**布局**、**外观**和**文字排版**分组便于修改属性。独立画布连接失败时可重试，管理界面仍可显示已保存的图层和属性。
- **转换副本** 保留原项目，导入原生 DOM/CSS、文字与素材，并适配可识别的导航、设置开关和上下文页面状态。原脚本留在副本源码中，其他旧事件处理与运行状态需要补写新脚本；转换提示会列明范围，使用前对照原画面。完整命令、脚本 API、迁移限制和性能验收目标见 [Design Studio 说明](../../DESIGN_STUDIO.md)。

跨电脑同步设计时，先关闭发送端 LeafLoom，同步整个项目文件夹（含素材）及其 `.vault-rag/design-studio` 历史，等同步完成后再在接收端打开。项目在知识库内的相对路径应保持一致，Windows 与 Mac 的知识库根路径可以不同。两端都应使用修复后的版本，并且一次只在一台电脑编辑。打开项目不会改写历史归属；不同目录复用同一项目 ID、中断保存与外部内容冲突时仍会拦截。需要独立副本时，请使用项目首页的 **复制**。

设计项目的 **回收站** 支持恢复、**永久删除项目** 和 **清空项目回收站**。永久操作会列出项目并要求确认；项目文件、设计历史及相关项目管理撤销记录将移除，其他项目和共享库不受影响。


如果项目首页提示后台尚未加载项目管理功能，请从托盘／菜单栏退出应用后重新启动；只刷新页面不会加载新的后台接口。管理状态读取成功前，删除、移动等按钮暂不可用，可用“重试”重新连接。

**复制源图片。** 在设计工作台单选图片，切到右侧 **设计** 页签，在 **图片来源** 卡片点击 **复制图片**。卡片显示缩略图、文件名及知识库相对路径，并解析当前绑定、变体和以图片为根的组件覆盖所使用的素材。复制保留源图片尺寸与透明背景，不包含画布裁剪、圆角或旋转。锁定图片和只读变体也可复制，无需先保存，不增加项目历史。画布或图层列表获得焦点时，**⌘C / Ctrl+C** 复制单张图片；其他元素和多选仍复制定位信息，图片菜单也保留 **复制控件定位信息**。输入框正常复制文字。PNG 可粘贴到其他软件或笔记，笔记沿用已有附件上传流程。SVG 转为静态图片，动图只复制首帧。仅支持项目内源图，外链需先导入；文件缺失、读取或解码失败会明确提示并支持重试，不会改成复制链接或文字。源文件及 PNG 不超过 32 MiB，图片不超过 6400 万像素。桌面端更新原生剪贴板支持后需重启 LeafLoom。

## 完成后的表现

文字、图层、素材与项目修改保存到各自项目中。

## 没有成功时

保存失败时保留待提交修改；转换副本需与原页面对照。

**外部源码编辑。** 可以用文本编辑器或 AI 工具修改 `Design/studio/project.json`。下一次打开或重新加载时，完整且合法的文档会自动接入为一条「外部文件修改」历史，支持撤销和重做，原文件不会被重新写入。只有格式变化时不新增历史。旧窗口保存仍会触发版本冲突并保留待保存修改，应重新加载后核对合并。JSON 未写完或格式错误时，完成或修正外部编辑后重试。中断保存与外部内容冲突、历史不完整的情况仍保留保护。更新此功能后需重启 LeafLoom。

# 让 AI 修改当前设计

## 使用目标

把明确选中的项目上下文交给 AI，应用一批可撤销的修改。

## 开始前

先打开一个设计项目，并等待已保存状态。

## 操作步骤

在设计工作台选择元素，使用 **添加到 AI 对话** 附加项目、页面、稳定 ID 和当前版本，再描述布局、素材、组件、动画或脚本的修改。内置助手只能修改当前对话明确附加的设计项目。一批设计修改直接应用，并形成一个持久撤销步骤；版本冲突时保留较新的设计。脚本播放状态不会写入设计历史。脚本接口与导出见 [Design Studio](../../DESIGN_STUDIO.md)。

使用外部 AI 时，在画布控件或左侧图层上右键，选择 **复制控件定位信息**（属性面板也有同名按钮，支持按住 Shift 多选；右键已选控件会保留多选），粘贴后描述修改要求。精简 JSON 只包含设计源文件的绝对路径 `file`、页面 `page_id`（主组件为 `component_id`）和控件 `node_id`（多选时为 `node_ids` 数组）；仅在变体视图或有待保存修改时附加 `variant_id` 或 `has_pending_changes:true`。先等待保存，再让 AI 读取最新设计并通过带版本检查的设计操作修改，以保留撤销历史。

画布或图层获得焦点时，按 **⌘+C**（Mac）或 **Ctrl+C**（Windows）复制非图片单选或多选的定位信息。单选图片时会复制源图片；需要图片的定位信息时请明确选择 **复制控件定位信息**。文字编辑、输入框、源码编辑器及普通文字选区仍正常复制文字；预览模式保持原有行为。

**复制源图片。** 在设计工作台单选图片，切到右侧 **设计** 页签，在 **图片来源** 卡片点击 **复制图片**。卡片显示缩略图、文件名及知识库相对路径，并解析当前绑定、变体和以图片为根的组件覆盖所使用的素材。复制保留源图片尺寸与透明背景，不包含画布裁剪、圆角或旋转。锁定图片和只读变体也可复制，无需先保存，不增加项目历史。画布或图层列表获得焦点时，**⌘C / Ctrl+C** 复制单张图片；其他元素和多选仍复制定位信息，图片菜单也保留 **复制控件定位信息**。输入框正常复制文字。PNG 可粘贴到其他软件或笔记，笔记沿用已有附件上传流程。SVG 转为静态图片，动图只复制首帧。仅支持项目内源图，外链需先导入；文件缺失、读取或解码失败会明确提示并支持重试，不会改成复制链接或文字。源文件及 PNG 不超过 32 MiB，图片不超过 6400 万像素。桌面端更新原生剪贴板支持后需重启 LeafLoom。

## 完成后的表现

MCP 默认先返回分页摘要；按页面／元素或资源 ID 定位后，再以 `full=true` 读取所需源码。沿 `next_offset` 翻页时传 `expected_revision`；修改与导入默认短回执。无选择条件的 `full=true` 和修改工具的 `include_document=true` 保留完整文档访问。更新后重启后端并刷新客户端工具，详见 [MCP 契约](../../MCP.md)。

设计修改直接应用，一批对应一个持久撤销步骤。

## 没有成功时

桌面端使用系统剪贴板复制；更新后重启 LeafLoom，使新的复制支持生效。

版本冲突时先检查较新的设计，不要反复强制重发旧修改。

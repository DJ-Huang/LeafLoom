# 管理 MCP 权限与访问凭据

## 使用目标

明确控制每个连接能读写哪些资源。

## 开始前

先区分本机 AI 连接与 ChatGPT Tunnel。两者写入默认关闭。

## 操作步骤

1. 在 **设置 → AI 连接 → MCP 访问权限** 中选择对应连接。
2. 按需启用笔记或飞书读取；需要保存时另启用写入。完整笔记读取包括未勾选 RAG 的笔记。
3. 首次启用本机访问时复制一次显示的专用配置，私下保存到目标客户端。
4. 飞书高风险操作需独立开关，并且每次操作仍要明确确认。
5. 轮换凭据后更新客户端；关闭全部资源权限或重新生成凭据会使旧凭据失效。

## 完成后的表现

关闭某一资源权限立即阻止该资源，但其他已授权资源可继续使用。旧兼容连接不自动获得完整权限。

## 没有成功时

认证错误先核对连接和凭据；不要靠开启全部写入排查。MCP 凭据不能用作网页登录或飞书账号凭据。

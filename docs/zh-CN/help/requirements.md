# 使用前需要准备什么

## 使用目标

选择适合当前电脑的安装方式。

## 开始前

准备 Windows 10/11 x64，或 macOS 14+ Apple Silicon。

## 操作步骤

1. 从官网下载对应平台安装包。Intel Mac 不受支持。
2. 准备有读写权限的本机目录；先备份重要资料。
3. 首次下载安装包、可选模型及连接外部服务需要网络。
4. 普通用户无需安装 Python、Node、uv、Ollama 或克隆仓库。

## 完成后的表现

安装后可直接阅读、编辑、浏览图谱和使用关键词检索。

## 没有成功时

语义检索需要额外准备 BGE-M3。源码开发另需 Node 22+ 与 uv，详见[开发说明](../../DESKTOP.md#source-development)。

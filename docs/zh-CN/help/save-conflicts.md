# 处理未保存草稿与版本冲突

## 使用目标

保留自己的修改，同时核对磁盘或外部客户端的新版本。

## 开始前

不要刷新、丢弃唯一草稿或反复重发旧写入。先复制重要草稿到安全位置。

## 操作步骤

1. 判断是普通自动保存，还是已接受 AI 修改后的手动草稿。
2. 手动草稿用 **保存草稿** 或 `Ctrl/⌘+S`。
3. 如果磁盘已变化，重新读取并对照两份内容，明确合并后保存。
4. 设计项目保留待提交操作；网络错误可重试，版本冲突先审查再选择重应用。
5. MCP 冲突也需重新读取版本。

## 完成后的表现

保存成功后再切换、预览或退出，原文和需要保留的草稿都有明确去向。

## 没有成功时

已保存内容与索引更新是两个阶段。保存成功、索引待更新时不要再次创建同名内容。

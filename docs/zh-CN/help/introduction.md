# LeafLoom 能做什么

## 使用目标

用自己的文件建立可编辑、可检索、可连接的个人知识库。

## 开始前

准备一个本机资料目录，或使用内置虚构演示库。

## 操作步骤

1. 阅读与编辑 Markdown，使用双链、属性和图谱连接想法。
2. 选择目录进行本地知识检索；需要时再下载语义模型。
3. 管理附件，打开 HTML 项目，或在设计工作台制作与发布画板。
4. 按需接入 AI 对话、MCP 客户端和飞书。

## 完成后的表现

笔记继续保存在原目录；索引、历史、评论与回收区在该目录的 `.vault-rag/` 中。

## 没有成功时

LeafLoom 不是云同步或完整 Obsidian 插件运行环境。外部 AI 和飞书的请求会联网。

# 搜不到笔记或语义检索未就绪

## 使用目标

按文件、范围、索引和模型逐项定位。

## 开始前

保留原始资料，准备一篇确定存在的 Markdown 或 TXT 笔记。

## 操作步骤

1. 按 `Ctrl/⌘+K` 搜文件名，确认路径和当前关联知识库。
2. 检查检索范围是否勾选该目录，及排除目录、`.ragignore`、笔记退出索引属性。
3. HTML 与附件不会进入语义检索；用文件浏览或附件管理找它们。
4. 查看搜索与索引状态，区分模型下载、校验、建索引和关键词/Wiki 降级。
5. 需要时使用重新同步索引并观察进度，再用原文里的明确关键词重试。

## 完成后的表现

确定是文件查找、检索选择还是语义准备问题。

## 没有成功时

不要一开始重装应用或删除索引。后台任务错误先保留诊断；索引就绪也不保证每个自然语言问题都有匹配。

# 准备语义模型与索引

## 使用目标

需要语义检索时再准备本地 BGE-M3 模型。

## 开始前

已选择检索目录。首次下载需要网络和可用磁盘空间。

## 操作步骤

1. 打开 **设置 → 搜索与索引**，查看模型状态与实际保存路径。
2. 明确选择下载模型，观察连接、下载和校验阶段。
3. 关闭设置后下载可继续；退出应用会中断。失败后保留诊断并重试，可复用已有下载。
4. 模型就绪后继续观察独立的建索引进度，再尝试语义检索。

## 完成后的表现

阅读与编辑一直可用。未准备模型或索引时可能使用关键词/Wiki 降级，不代表语义准备完成。

## 没有成功时

30 秒无进度会显示等待提示。打开模型目录只显示文件，不会开始下载。不要通过删除笔记解决下载问题。

# LeafLoom 0.1.8 — 设计工作台与 Markdown 目录

发布日期：2026-11-05 · 相对 v0.1.7 的更新

[English](../en/RELEASE_NOTES_0.1.8.md) · [中文](RELEASE_NOTES_0.1.8.md) · [日本語](../ja/RELEASE_NOTES_0.1.8.md)

## 整理与对比设计

页面可归入可折叠文件夹，支持批量移动、重命名或合并文件夹及移回未分组。图层栏与属性栏可以独立收起。**对比**模式左侧编辑、右侧交互预览，保存后刷新。

## 复制原图与控件定位信息

单张原图可按原尺寸和透明背景复制为 PNG，支持绑定和变体，不修改项目。使用 Cmd+C／Ctrl+C、右键菜单或属性面板复制单个或多个控件的精简定位信息；文字和源码编辑仍保留原有复制行为。升级后重启 LeafLoom，以使用更新的桌面剪贴板通道。

## 导航 Markdown 笔记

新增可折叠本页目录，跟随当前章节，支持折叠标题子树、在正文或源码模式跳转并随编辑更新；窄窗口使用浮层。

## 更高效的附件同步

目录扫描间隔随活跃度调整，上传后针对相关目录复查；空闲资料和分组拉取及失败重试逐渐降低频率，计划在重启后保留，并可从缓存目录被外部删除的情况恢复。手动完整核对仍立即执行。

## 升级与平台

备份知识库和元数据，退出 LeafLoom，安装对应版本后重新打开知识库。源码用户更新后重启。安装包适用于 Windows x64 和 macOS 14+ Apple Silicon；Windows 未签名，macOS 使用临时签名且未经 Apple 公证。请查看本版本发布附件、SHA256SUMS.txt 和构建结果。

# LeafLoom 0.1.5 — 附件服务器、AI 素材与演示

## 本地与服务器附件统一浏览

在 **设置 → 附件服务器** 填写地址、账号和密码，即可连接通用 WebDAV 或 SMB2/3 服务。更改新附件保存位置不会搬动已有文件，也不改变已有资料库绑定。笔记仍在本地知识库，服务器原件按需读取或下载。

附件界面以文件为主：紧凑工具栏、按需打开的概览、可折叠详情，以及不支持直接预览格式的已有封面展示。分组可手动管理，也可按来源、目录、格式、分类和标签收录。切换分组时标题、列表与数量一起更新，读取失败不会把旧列表留在新标签下面。**下载** 独立成页，新建与导入移到文件目录操作。

## 自动同步，断线后接着扫描

连接恢复后自动发现目录，每轮完成五分钟后再次检查。已完成目录保存在本机断点中，断线或应用重启后可继续；后续检查复用十分钟内的目录缓存，到期子目录独立核对。**同步状态** 展示进度、复用数量和当前重连／同步过程，临时连接原因默认折叠；认证失败仍需更新凭据。

没有变更日志的服务器仍需定期查询目录。升级后的首次扫描会建立断点，并非实时变更流。未完成的扫描保留原有记录。迁移、整理入口已隐藏，底层任务记录与恢复材料继续保留。

## 为 AI 明确选择素材范围

在需要的附件分组中开启 **用于 AI 素材检索**，AI 才能查询该范围的资料、查看已有预览，并将校验过的原件交付到指定本机目录。可选的本地语义排序与笔记检索相互独立；未选分组时不回退到全库。这不包含自动导入 Unity，也不证明素材购买权属。

已有 Unity 资源包可保留官方商品资料、多版本、个人标签和真实封面。可选采集会核对官方商品身份、保留个人整理，并支持批量续采。分组、引用与资料通过已验证的服务器记录同步，冲突需明确处理；使用中的 SQLite 留在本机。

## Design Studio 演示与 AI 操作

全屏预览按比例适配画板，交互不会重新开始。桌面演示者模式提供独立观众屏幕、实时控制预览、私人讲稿、步骤导航、黑屏与断线恢复；讲稿保留在项目历史中，不进入观众文档或导出结果。

设计 MCP 新增分页摘要和按页面／元素／资源读取源码，修改结果使用简洁回执；服务器端素材导入减少大文件往返。笔记内容和历史保存完成后立即确认，后台处理资料更新，修复保存响应相互等待的问题。

## 升级与兼容说明

1. 先备份知识库，保留应用资料、待上传队列及恢复文件，完全退出 LeafLoom 后再替换应用。
2. 安装对应平台版本，重新打开原知识库，等待凭据恢复和首次断点建立。已有服务器 ID、根目录、上传目录及资料库绑定沿用原值。
3. 更新后刷新 MCP 客户端工具列表；源码版更新代码后使用 **重启 LeafLoom**。Dev 与安装版共用同一用户配置。

安装包面向 Windows x64 与 macOS 14+ Apple 芯片。Windows 未签名，macOS 为临时签名且未经 Apple 公证，请核对 `SHA256SUMS.txt` 与关联的原生构建报告。CI 不代表所有 NAS、VPN 和实体双屏组合均已通过验证；Windows 演示硬件覆盖单独记录。

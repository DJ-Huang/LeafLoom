| CI | 已加入手动 Windows/macOS ARM64 工作流；尚未提交或运行远程 CI |

原仓库日志位于 `%LOCALAPPDATA%\VaultRag\logs`。隔离安装机器可读报告为 `_generated/install-validation.json`，包含临时目录、平台、时间、模型复用与后台任务验证方式；报告中的临时目录保留完整日志。知识库目录没有关联到验收实例。

实测修复了 Windows 停止状态的一秒超时误判。当前仓库更新还复现了 Python Proactor 网络连接重置后的退出卡住；服务器改用 Windows Selector TCP 事件循环，并限定 HTTP 任务退出等待时间。本次清理了自行创建、没有关联知识库的卡住测试进程；安装器本身遇到停止超时会保留进程并提示，不会强制结束其他 Python。

旧 Mac 制品未在 Windows 上重新编译。启动器会识别维护端新版菜单标记；当前旧制品使用系统 AppKit 兼容菜单，维护端编译新版 ARM64/macOS 14 程序后自动使用预编译程序。两种方式的 Mac 实际运行仍需在原生设备上确认。

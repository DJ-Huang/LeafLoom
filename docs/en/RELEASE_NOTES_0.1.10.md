# LeafLoom 0.1.10 — Open and share design projects

Release date: 2026-11-19 · Changes since v0.1.9

[English](../en/RELEASE_NOTES_0.1.10.md) · [中文](../zh-CN/RELEASE_NOTES_0.1.10.md) · [日本語](../ja/RELEASE_NOTES_0.1.10.md)

Open an existing Design Studio project outside your vault as read-only. Enable editing when you want the studio to save changes in its folder. Removing it from the list leaves its files in place.

Export a project as a ZIP package and import it into another vault as an independent copy. Existing folders are not overwritten.

Back up your vault and metadata, quit LeafLoom, install the matching package and reopen the same vault. Source users should update and restart LeafLoom. Windows x64 is unsigned; macOS 14+ Apple Silicon uses ad-hoc signing without Apple notarization. Check the release assets, SHA256SUMS.txt and build results before installation.

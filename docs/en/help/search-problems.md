# Fix missing search results or a pending index

## Your goal

Check files, retrieval scope, indexes and models in order.

## Before you start

Keep originals and choose a Markdown/TXT note you know exists.

## Steps

1. Use `Ctrl/⌘+K` to check the filename, path and current vault.
2. Inspect selected folders, exclusions, `.ragignore` and note opt-out properties.
3. HTML and attachments are not semantic-retrieval content; use browsing or the attachment manager.
4. Distinguish model download, verification, indexing and keyword/Wiki fallback.
5. Resynchronize the index if needed, observe progress and retry an explicit phrase from the note.

## What to expect

You can distinguish file lookup, scope selection and semantic preparation problems.

## If it does not work

Do not start by reinstalling or deleting indexes. Retain diagnostics. A ready index cannot guarantee a match for every question.

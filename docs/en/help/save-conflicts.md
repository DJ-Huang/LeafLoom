# Resolve unsaved drafts and version conflicts

## Your goal

Preserve your edits while checking newer disk or client changes.

## Before you start

Avoid refreshing, discarding the only draft or repeatedly resending stale writes. Copy critical drafts somewhere safe.

## Steps

1. Identify ordinary autosave versus a manual draft after accepting AI changes.
2. Use **Save draft** or `Ctrl/⌘+S` for manual drafts.
3. If disk content changed, reread both versions and merge explicitly.
4. Design projects retain pending operations. Retry network errors; review version conflicts before reapplying.
5. MCP conflicts require fresh revisions too.

## What to expect

After a confirmed save, switch, preview or quit with both originals and needed drafts accounted for.

## If it does not work

Saving and index refresh are separate stages. A saved-but-index-pending result is not a reason to create duplicate content.

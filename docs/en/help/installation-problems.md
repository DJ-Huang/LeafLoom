# Fix blocked installation or startup

## Your goal

Separate unsupported platforms, OS blocking, old instances and backend loading.

## Before you start

Record app/OS versions, download source and redacted errors.

## Steps

1. Check Windows x64 or macOS 14+ Apple Silicon and the matching package.
2. If the OS blocks it, verify the official Release source and read the exact reason; keep global protections enabled.
3. Quit any old instance through its tray before reopening. Closing the window may leave it running.
4. A page refresh does not update Python/Electron; restart LeafLoom after source changes.
5. Open the log folder from desktop General settings and capture the first startup error with private details removed.

## What to expect

You can identify whether the failure is installation, a busy port, a backend mismatch or the UI.

## If it does not work

Do not delete notes, models, credentials or history to fix a blank page. Report reproducible steps and redacted logs if it persists.

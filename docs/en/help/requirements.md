# What to prepare before you start

## Your goal

Choose an installation that matches your computer.

## Before you start

Use Windows 10/11 x64 or macOS 14+ on Apple Silicon.

## Steps

1. Download the installer for your platform. Intel Macs are unsupported.
2. Choose a writable local folder and back up important notes.
3. Installer/model downloads and external services require internet access.
4. End users do not need Python, Node, uv, Ollama or a repository checkout.

## What to expect

After installation, reading, editing, graphs and keyword search are available.

## If it does not work

Semantic search additionally requires BGE-M3. Source development needs Node 22+ and uv; see [development setup](../../DESKTOP.md#source-development).

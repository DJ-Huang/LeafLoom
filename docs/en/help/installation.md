# Install and open LeafLoom

## Your goal

Install the desktop app and reach its welcome screen.

## Before you start

Check [system requirements](requirements.md) and save other work.

## Steps

1. Choose Windows or Mac from the [website](../../../README.md) downloads.
2. Windows: run `LeafLoom-*-windows-x64-setup.exe`, complete the wizard and open the app from Start.
3. Mac: open `LeafLoom-*-macos-arm64.dmg`, drag the app into Applications and launch it there.
4. If blocked, verify the download source and read [installation problems](installation-problems.md).
5. Choose a language and try the demo or connect a folder.

## What to expect

The welcome screen lets you choose your folder without first downloading a retrieval model.

## If it does not work

Current packages lack a trusted distribution signature; Mac builds are ad-hoc signed and not notarized. Keep global system protections enabled.

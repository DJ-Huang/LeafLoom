# What you can do with LeafLoom

## Your goal

Build an editable, searchable and connected knowledge base from your own files.

## Before you start

Prepare a local folder, or try the built-in fictional demo.

## Steps

1. Read and edit Markdown; connect ideas with links, properties and graphs.
2. Select folders for local retrieval; download the semantic model when needed.
3. Manage attachments, open HTML projects, or create and publish design artboards.
4. Optionally connect AI Chat, MCP clients and Feishu.

## What to expect

Notes remain in their original folder. Its `.vault-rag/` holds indexes, history, comments and trash.

## If it does not work

LeafLoom does not provide cloud synchronization or every Obsidian plugin. External AI and Feishu requests use the network.

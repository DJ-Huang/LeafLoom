# Write and find your first note

## Your goal

Complete a small create, edit, link and reopen workflow.

## Before you start

Use a [connected vault](first-vault.md), preferably the demo.

## Steps

1. Choose **New note**, an existing parent folder and a new filename.
2. Write a paragraph; use `/h2` for a heading and `/todo` for a task.
3. Type `[[` and select another note by its full path.
4. Wait for ordinary autosave, switch away and return to inspect it.
5. Press `Ctrl/⌘+K`, enter the filename and reopen the note.

## What to expect

A normal Markdown file appears in your folder and is readable by other editors.

## If it does not work

For a manual AI draft, use **Save draft** or `Ctrl/⌘+S`. Keep the draft if a conflict appears.

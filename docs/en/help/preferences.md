# Set language, folders and background behavior

## Your goal

Adjust everyday settings and reload or stop the app correctly.

## Before you start

Save pending work, especially manual AI drafts.

## Steps

1. Choose Chinese, English, Japanese or system language in **Settings → General → Interface language**.
2. Switch the connected vault in Settings; paths and scope belong to the selected vault.
3. Change login startup in desktop settings or the tray; it is initially off.
4. Use **Restart LeafLoom** in the app/tray menu. Return from the unsaved prompt to cancel.
5. Closing hides the window; **Quit** stops local services and connections.

## What to expect

Language changes retain documents, drafts and location without reindexing. Dev restart keeps Vite and synchronizes dependencies.

## If it does not work

Dev and the installed app share real data and the normal port. Quit one before switching. Use an explicit separate data directory for isolated development.

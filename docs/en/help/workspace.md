# Find your way around the workspace

## Your goal

Choose the right entry for files, retrieval, attachments, design or settings.

## Before you start

Open a vault. Change interface language in General settings.

## Steps

1. Browse files in the left directory tree; Home includes recent content and an onboarding checklist.
2. Use knowledge search for evidence, the graph for connections, and `Ctrl/⌘+K` for file names.
3. Open Attachments for media, Preview for URLs, and Design Studio for editable projects.
4. AI Chat is optional; Settings holds scopes, connections, history and trash.
5. Getting started restores the checklist; Help center opens documentation in the current language.
6. Right-click a folder or filename in the top path bar for **Copy relative path** or **Copy absolute path**. Relative paths start at the vault root (`.` for the root); absolute paths use the service computer's path format. You can also focus a path and press **Shift+F10**, or click the current filename/folder name.

## What to expect

Each content type has a workspace; browsing does not require retrieval selection.

## If it does not work

Closing the window normally hides it to the tray. Use **Quit** to stop the service.

# Check for and install updates

## Your goal

Check your version and upgrade through the normal installer.

## Before you start

Save work, read the [changelog](../../../CHANGELOG.md) and back up important material.

## Steps

1. Open **Settings → General → App updates → Check for updates**.
2. Choose **Download and install** and inspect download progress.
3. After SHA-256 verification, quit normally. If you cancel quitting, use **Continue installation** later.
4. Complete the Windows wizard, or replace the Mac application from the DMG and reopen it.
5. Dev checks versions only; update the source and rerun Dev.

## What to expect

Upgrades retain notes, settings, indexes and models. Keep a backup regardless.

## If it does not work

Retry failed checks or downloads. Refreshing the page does not upgrade the backend. Follow the actual installer version shown for each platform.

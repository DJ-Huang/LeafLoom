# LeafLoom 0.1.5 — Release Notes

Compared with v0.1.4, this release adds general attachment tools for local MCP clients and the LeafLoom ChatGPT plugin:
- `vault_files` reads attachment metadata, original bytes, ZIP downloads and task status.
- `vault_files_update` handles authorized uploads and recoverable organization, moves and trash operations.
- Shared workspace permissions, revision checks, durable recovery receipts and bounded HTTPS download safeguards.

Windows packages are unsigned. macOS uses ad-hoc signing without Apple notarization. Verify artifacts and checksums before publishing.

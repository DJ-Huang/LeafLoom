# LeafLoom 0.1.4 — Release Notes

Changes since v0.1.3:
- Markdown inline annotations, threaded comments, improved anchors and grouped undo history.
- Attachment indexing and consolidation, expanded attachment workspace, desktop restart workflows.
- General file tools and portable Design Studio history/sync.
- Multilingual public help center.
- GitHub Pages latest-release synchronization safeguards.

Windows is unsigned and macOS uses ad-hoc signing without Apple notarization. Verify installers before publishing.

## Additional features included in refreshed 0.1.4 build

Compared with v0.1.3, this release adds general attachment tools for local MCP clients and the LeafLoom ChatGPT plugin:
- `vault_files` reads attachment metadata, original bytes, ZIP downloads and task status.
- `vault_files_update` handles authorized uploads and recoverable organization, moves and trash operations.
- Shared workspace permissions, revision checks, durable recovery receipts and bounded HTTPS download safeguards.

Windows packages are unsigned. macOS uses ad-hoc signing without Apple notarization. Verify artifacts and checksums before publishing.

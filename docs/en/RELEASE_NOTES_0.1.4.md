# LeafLoom 0.1.4 — Release Notes

Changes since v0.1.3:
- Markdown inline annotations, threaded comments, improved anchors and grouped undo history.
- Attachment indexing and consolidation, expanded attachment workspace, desktop restart workflows.
- General file tools and portable Design Studio history/sync.
- Multilingual public help center.
- GitHub Pages latest-release synchronization safeguards.

Windows is unsigned and macOS uses ad-hoc signing without Apple notarization. Verify installers before publishing.

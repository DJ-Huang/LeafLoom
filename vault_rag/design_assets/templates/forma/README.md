# FORMA Editorial Studio

Original LeafLoom starter, distributed under the repository MIT license.

The canonical managed document contains 4 artboards and 328 editable native layers. All artwork is made from native shapes and CSS in the document; no external images, fonts, scripts or asset downloads are required. `preview.jpg` is a rendered preview of the home artboard.

## Make it your own

- Open page settings to replace the brand and footer contact caption across all four artboards. Explicit text bindings update only the logo and footer credits, preserving unrelated copy.
- Each **Page · brand and layout styles** root links three shared styles: **FORMA / Brand palette**, **FORMA / Type families**, and **FORMA / Layout rhythm**. Edit their named values to update the paper, ink, accents, fonts, gutters and section spacing together. The CSS custom properties remain linked in preview and exported HTML.
- **FORMA / Caption** gives section labels a shared typographic treatment while desktop/mobile CSS retains the appropriate font sizes.
- Named Header, Hero, Selected work, Case study, About and Footer groups organize editable text, project cards and original artwork. Text is not flattened into screenshots. CSS artwork can be edited as layers; project images can be inserted or replaced with the regular image tools.
- Styles are independent: a local element edit overrides a shared value; applying the style again restores the link, and detaching a style preserves its current appearance. All edits use ordinary project history.

Only the canonical document and preview are packaged. Creation assigns a fresh project identity and installs the current runtime; no original project history, exports, sessions or machine paths are copied.

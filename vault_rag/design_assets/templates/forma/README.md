# FORMA Editorial Studio

Original LeafLoom starter, distributed under the repository MIT license.

The canonical managed document contains 4 artboards and 328 editable native layers. All artwork is made from native shapes and CSS in the document; no external images, fonts, scripts or asset downloads are required. `preview.jpg` is a rendered preview of the home artboard.

Only the canonical document and preview are packaged. Creation assigns a fresh project identity and installs the current runtime; no original project history, exports, sessions or machine paths are copied.

# GitLab 适配

只在采集指定 GitLab 代码活动时加载；通用归档与去重遵循 [来源采集与入库](imports.md)。写 `source_provider: gitlab`、`source_kind: code`，`source_id` 包含实例、仓库与提交 SHA 或 MR 身份。


只采集指定仓库/分支和日期范围，核对本人作者身份、提交日期及 MR 中的实际角色。优先用已连接的读取工具，必要时在已授权本地克隆用 git 读取；未推送/未更新的本地克隆标明覆盖范围。

提交用仓库身份 + 完整 SHA 去重；同一提交跨分支不重复。活动推送事件只作定位线索，批量 push 数量不是实际提交明细或个人工作量；从真实提交/MR 内容核实。自建实例过滤/分页语义以当前响应为准。连接失败标为 unavailable，保留其他来源的成功结果。
